### cmux
- URL: https://cmux.com/
- Kind: agent-native
- What: A GPU-accelerated native macOS terminal (built in Swift/AppKit using libghostty) with vertical workspace tabs, notification rings, scriptable in-app browser, and session restore, purpose-built for running multiple AI coding agents in parallel. KANBAN/board view of agent tasks: no (uses a vertical tab sidebar with status pills, notification rings, and split panes; no multi-column kanban board).
- Agent integration: Unix socket API (/tmp/cmux.sock) and CLI (`cmux`), terminal escape sequences (OSC 9/99/777), native Claude Code hooks (`cmux hooks setup`), a custom tmux shim (`cmux claude-teams`) translating tmux calls into cmux splits for Claude Code Teams, and `cmux-skills` (covering Claude Code, Codex, OpenCode, Gemini CLI, Cursor CLI, Amp, Aider, Goose, Cline, pi, and oh-my-opencode).
- Mobile: Native iOS beta app ("cmux BETA" distributed via TestFlight, requires cmux Founder's Edition early access); pairs with Mac over local network, Auto-Connect, or Tailscale/WireGuard overlay; supports viewing/inputting to remote terminal workspaces and receiving forwarded Apple push notifications (cite: https://cmux.com/docs/ios).
- Pricing: Free and open-source core app; optional "cmux Founder's Edition" ($100 one-time / sponsorship via Stripe) for early access to iOS TestFlight app, cmux AI, cloud VMs, and voice mode (as of 2026-10-16).
- Self-host: Yes (local desktop app runs entirely locally on macOS; optional relay/server services under `web/` and Cloudflare workers can be self-hosted for non-production use or licensed commercially for production; no enterprise cloud lock-in for core terminal features).
- License: Open-source (GPL-3.0-or-later for macOS app, iOS app, CLI, and cmux-tui; Business Source License 1.1 / BUSL-1.1 for cmux server software and cloud relay workers in `web/` and `workers/`).
- Activity: 28,199 GitHub stars; last pushed 2026-10-16T03:13:55Z; active rapid development with daily/nightly builds.
- Pros: True native Swift/AppKit performance with libghostty GPU rendering instead of Electron; seamless drop-in tmux shim for Claude Code Teams turning subagents into native splits; programmable in-app browser with accessibility tree snapshots for agents to visually verify work; comprehensive session restore across app quits and reboots; direct socket and CLI APIs for custom automation.
- Cons: macOS only for desktop host (Linux/Windows not supported as host); no native Kanban/board view for task tracking; iOS companion requires keeping host Mac awake and configured; production self-hosting of relay server infrastructure requires commercial license under BUSL-1.1.

### CNVS

KANBAN/board view of agent tasks: no (provides an infinite 2D spatial canvas with freeform cards, a Stage rail/grouped sidebar, a Tasks node checklist, and a multi-canvas "shelf" view, but not a traditional multi-column kanban board).

- Mobile: Native iOS companion app ("CNVS Pocket" on iPhone, featuring end-to-end encrypted push notifications for agent completions, failures, and interactive prompts/questions with lock-screen action buttons; cite: https://cnvs.dev/release/1-5-2-distraction-guard/).
- Pricing: Commercial paid product with no subscription; tiered lifetime license pricing on founder ratchet: $99 one-time (founder initial tier), scaling to $129 and $169 for subsequent license batches; includes all 1.x updates forever; BYOK / uses your existing AI agent subscriptions (as of 2026-10-16).
- Self-host: Yes (local native desktop application running entirely on macOS; agent processes and local control server run locally; canvases can run locally or over user-configured VPS/relays; no mandatory cloud server).
- License: Proprietary (closed source commercial software).
- Activity: Version 1.5.2 "Distraction Guard" shipped September 20, 2026; Version 1.4.0 "Shorthand" shipped August 3, 2026; Version 1.3.2 "Nightglass" shipped June 17, 2026; active development by solo/studio team.
- Pros: Spatial canvas allows visual organization of terminals, previews, browser panes, notes, and agent cards in one place; voice-first control for spawning and steering agents without keyboard context switching; Distraction Guard with verbatim question/failure tiles and E2EE iPhone alerts via CNVS Pocket; runs on-device summarization using Apple Intelligence with zero per-request token overhead; one-time lifetime payment model without recurring subscriptions.
