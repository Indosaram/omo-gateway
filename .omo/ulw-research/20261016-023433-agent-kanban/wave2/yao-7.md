### Supacode
- URL: https://supacode.sh/
- Kind: agent-native
- What: A native macOS desktop command center built on libghostty that runs 50+ AI terminal coding agents in parallel across isolated Git worktrees with background session persistence via zmx. It has NO Kanban or task-board view; agent tasks and worktrees are organized and tracked via a live sidebar list, menu bar applet, command palette, and terminal tabs with presence status badges (busy, awaiting input, idle).
- Agent integration: CLI agent hook presence and deeplinks (`supacode://...`); bundled CLI tool (`supacode`) managing worktrees, tabs, splits, and repos; supports Claude Code, OpenAI Codex, OpenCode, Kimi Code CLI, Grok Build, Hermes, Oh My Pi, Antigravity (agy), Copilot, and any CLI-based coding agent.
- Mobile: none (macOS desktop application only, requires macOS 26 Tahoe; no iOS app, no Android app, no mobile web view).
- Pricing: Commercial source-available model with free trial. Free tier gives first 5 local worktree creations free across all repos on that Mac, with unlimited SSH remote worktrees free. Paid perpetual licenses include 1 year of updates: Basic at $99 USD (one user on 1 Mac), Standard at $129 USD (one user on 2 Macs; renewals at $59/year), and Team at $79 USD per seat/year (min 3 seats; as of 2026-10-16).
- Self-host: yes (Local desktop app; runs entirely locally on macOS without mandatory cloud dependency; remote SSH repositories supported in beta where an SSH host runs zmx for session persistence).
- License: Functional Source License, Version 1.1, ALv2 Future License (FSL-1.1-ALv2; source-available, converting to Apache-2.0 after a 2-year anniversary).
- Activity: Active; latest release v0.11.4 on GitHub (commits up to Oct 15, 2026; GitHub repo supabitapp/supacode).
- Pros: Blazing fast native Swift/AppKit UI with libghostty terminal rendering and no Electron overhead; Strong session persistence with zmx daemon surviving app quits and connection drops; Robust multi-worktree parallel isolation preventing git conflicts across multiple agents; Remote SSH worktree and terminal multiplexing capability; Rich ecosystem integrations for coding agent hooks and presence tracking.
- Cons: No Kanban or board view for agent work status; Restricted to macOS 26+ desktop (no cross-platform Windows/Linux or mobile companion); Closed-source/source-available commercial licensing requiring a purchase after 5 local worktrees; Lacks built-in MCP server for cross-agent orchestration or agent-driven task spawning; Focuses strictly on terminal multiplexing rather than structured task lifecycle management.
- Sources: https://supacode.sh/, https://yetanotherorchestrator.app/apps/supacode/, https://github.com/supabitapp/supacode, https://github.com/supabitapp/supacode/releases, https://raw.githubusercontent.com/supabitapp/supacode/main/LICENSE, https://raw.githubusercontent.com/supabitapp/supacode/main/AGENTS.md, https://github.com/supabitapp/supacode/commits/main
- Confidence: high

### Synara
- URL: https://www.trysynara.com/
- Kind: agent-native
- What: A free, open-source local-first workspace and control plane for AI coding agents combining threads, Git worktrees, terminal panels, browser verification, diffs, and pull-request delivery. It features a full KANBAN/board view of agent tasks under its Tasks/Inbox surface with an Attention board (columns: Draft, In Progress, Awaiting you, and Done) alongside a Classic 3-column board and list view.
- Agent integration: Official internal MCP server (Agent Gateway: `synara_create_thread`, `synara_create_threads`, `synara_wait_for_threads`, `synara_send_message`, `synara_create_todo`, `synara_list_todos`, `synara_update_todo`) and External MCP server (`synara-external` over stdio bridge with `synara_overview`, `synara_create_task`, `synara_wait_for_task`, `synara_read_task`) for Claude Code, OpenAI Codex, Cursor Agent, OpenCode v2, Devin CLI (via ACP), Antigravity (agy), Grok Build, Pi, Oh My Pi, and Factory Droid; loopback REST/HTTP API and CLI runner.
- Mobile: native iOS/iPadOS companion app in active TestFlight beta (TestFlight 0.1 (135) for Synara Remote; responsive web/headless server mode supported via `bun run dev`/release tarball; Windows, macOS Intel/ARM64, and Linux desktop native apps available).
- Pricing: Free and open-source (100% free under MIT license; no subscriptions, accounts, or cloud credit fees; users bring their own local agent CLI subscriptions and provider accounts; voluntary GitHub sponsors/donations).
- License: MIT License (T3 Tools Inc. and Emanuele Di Pietro).
- Self-host: yes (Local desktop application or headless server mode running via Bun/Node or release tarball; all task manifests, SQLite databases, and workspace files reside in `~/.synara` on the local machine with zero mandatory cloud relay).
- Activity: Highly active; stable v1.0.5 and beta v1.0.6-beta.1 / v1.0.6-remote.9 released on Oct 15-16, 2026 with 16,995+ automated tests passing; GitHub repo Emanuele-web04/synara with daily commits through 2026-10-16.
- Pros: Complete Kanban board and Attention view natively built for tracking agent status, approvals, and stalled tasks; First-class internal Agent Gateway and External MCP servers letting Claude Code, Codex, and others programmatically create, inspect, and update tasks and to-dos; Broad cross-platform support (macOS, Windows, Linux, headless server, and iOS companion); Deep multi-agent isolation with automated Git worktree management, split-diff reviews, and provider handoffs; 100% free and open-source under MIT with no vendor lock-in or cloud dependencies.
- Cons: Relatively heavy TypeScript/Electron/Bun workspace codebase spanning multiple monorepo packages; Early-stage rapid iteration with breaking changes across beta and remote branches; Full multi-folder workspace chats currently limited to Local mode with Codex or Claude; Mobile companion is currently restricted to Apple TestFlight with Android not yet published.

### Unpeel
- URL: https://unpeel.com/
- Kind: agent-native
- What: A native agent-first terminal multiplexer written in Rust with a libghostty-based macOS client and iOS companion that runs persistent CLI agent sessions across isolated Git worktrees. It has NO Kanban or board view of agent tasks (strictly rejects IDE and board chrome in its product philosophy); agent statuses (busy, idle, needs you) are displayed via a dashboard sidebar list, macOS menu bar item, and iOS mobile list.
- Agent integration: Official unified MCP server (`unpeel-host __mcp__`, injected automatically into managed launches with tools for `sessions`, `agents`, `workspace`, `artifacts`, `browser`, `apps`, and `skills`); bidirectional CLI (`unpeel ls --json`, `unpeel new`, `unpeel send`, `unpeel wait --idle`, `unpeel screen`, `unpeel logs`); supports Claude Code, OpenAI Codex, Gemini CLI, Cursor Agent, Amp, Grok, Kimi, Kiro, Cline, OpenCode, Muse Code, Antigravity, and Pi.
- Mobile: native iOS app (iPhone and iPad app `UnpeelIOS` written in SwiftUI with embedded libghostty terminal running on iOS 17+, available via TestFlight; pairs directly over local Wi-Fi/Bonjour or through end-to-end encrypted relay Unpeel Link).
- Pricing: Local product and server are free and open source. Optional cloud relay service (Unpeel Link for remote access away from LAN/VPN with push notifications) was originally listed in early directory copies as $59 per seat with 7-day trial, while current releases emphasize free download with local direct pairing at no cost (as of 2026-10-16).
- Self-host: yes (Open-source server daemon `unpeel serve` running on macOS or Linux x86_64/aarch64 via launchd/systemd with shared PTY core; stores all sessions, journals, and sockets under `~/.unpeel/`).
- License: MIT License (UX Themes AS; server, CLI, and client apps in open-source repo unpeel-com/unpeel; Link relay backend is proprietary).
- Activity: Active; version 0.7.5 in Cargo.toml workspace; active commits on main through Oct 14, 2026 (GitHub repo unpeel-com/unpeel).
- Pros: True persistent headless PTY architecture where sessions outlive client restarts and connection drops; Excellent mobile support with native iOS terminal app and remote screenshot markup gallery; Official unified Model Context Protocol server enabling inter-agent communication, screen reading, and sandboxed browser use; Lightweight Rust core (0.1–0.4 MiB memory footprint per session) with no Node.js runtime required; Open-source MIT core supporting macOS and headless Linux servers.
- Cons: Absolutely no Kanban or board view by design philosophy (strictly terminal, transcript, and sidebar list); Agent write interactions to other sessions require manual user approval policies; Unpeel Link encrypted relay for off-LAN mobile connections relies on a managed cloud service backend; Focused strictly on terminal/PTY streaming rather than visual code editors or diff inspectors.
- Sources: https://unpeel.com/, https://yetanotherorchestrator.app/apps/unpeel/, https://unpeel.com/docs, https://unpeel.com/docs/cli, https://unpeel.com/docs/unpeel-mcp, https://unpeel.com/privacy, https://github.com/unpeel-com/unpeel, https://raw.githubusercontent.com/unpeel-com/unpeel/main/crates/Cargo.toml, https://raw.githubusercontent.com/unpeel-com/unpeel/main/LICENSE, https://raw.githubusercontent.com/unpeel-com/unpeel/main/AGENTS.md, https://raw.githubusercontent.com/unpeel-com/unpeel/main/clients/ios/UnpeelIOS/project.yml, https://github.com/unpeel-com/unpeel/commits/main
- Confidence: high
