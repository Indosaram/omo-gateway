### Shrimp Task Manager MCP (cjo4m06/mcp-shrimp-task-manager)
- URL: https://github.com/cjo4m06/mcp-shrimp-task-manager (Official doc site: https://cjo4m06.github.io/mcp-shrimp-task-manager)
- Kind: agent-native
- What: Model Context Protocol (MCP) 기반 작업 관리 도구로, AI 에이전트의 복잡한 프로젝트 작업을 체계적으로 계획·분해·실행·검증하고 세션 간 컨텍스트를 유지(Persistent Memory)할 수 있도록 지원하는 작업 상태 관리 서버.
- Agent integration: 공식 MCP Server (StdioServerTransport 기반, 15개 MCP Tool 제공: plan_task, analyze_task, reflect_task, split_tasks, list_tasks, execute_task, verify_task, delete_task, clear_all_tasks, update_task, query_task, get_task_detail, process_thought, init_project_rules, research_mode); REST API (Web GUI 활성화 시 Express 기반 /api/tasks, /api/tasks/:id 및 Task Viewer 전용 REST API 제공); Server-Sent Events (SSE: /api/tasks/stream); CLI (shrimp-viewer CLI); 지원 에이전트는 Claude Code, Claude Desktop, Cline (VS Code 확장), Cursor 및 기타 MCP 표준 클라이언트 지원.
- Mobile: responsive web 지원 (전용 iOS/Android 네이티브 앱 없음, PWA 매니페스트 미제공, 내장 Express Web GUI 및 React 19 기반 Task Viewer는 CSS 미디어 쿼리 @media (max-width: 768px) 기반 모바일 반응형 웹 뷰 지원; 소스 코드 src/public/style.css 및 tools/task-viewer/src/index.css 확인).
- Pricing: open-source free (완전 무료 오픈소스, 2026-10-16 기준 유료 플랜/구독 티어 없음. 단, Task Viewer의 AI 에이전트 일괄 자동 할당 기능 사용 시 사용자 소유의 OpenAI API 키 호출 비용 발생).
- Self-host: yes (로컬 환경 자가 호스팅; Node.js 18+ 환경에서 Git 클론 후 npm install / npm run build 실행 또는 Smithery/Glama MCP 레지스트리를 통한 설치; Linux systemd 서비스 등록 스크립트 install-service.sh 제공; 태스크 데이터는 로컬 JSON 파일 tasks.json 및 Git 히스토리로 관리되며 엔터프라이즈 제한 없음).
- License: MIT License (https://github.com/cjo4m06/mcp-shrimp-task-manager/blob/main/LICENSE).
- Activity: GitHub Stars 약 150+개 추산(GitHub API Rate Limit 상태이나 Smithery/Glama 등록 활성 프로젝트), 최근 커밋 2025년 8월 21일(2025-08-21), 최신 패키지 버전 v1.0.21 (Task Viewer v3.0.0), 활성 오픈소스 상태.
- Pros: Claude Code, Cline, Claude Desktop 등 MCP 표준 지원 클라이언트와 완벽한 호환성 제공; 2가지 웹 뷰(내장 D3.js 기반 경량 의존성 그래프 Web GUI 및 React 19/TanStack Table 기반 고기능 Task Viewer) 동시 제공; tasks.json 변경 시 자동 Git 커밋 백업 및 타임라인 스냅샷 복원 기능 내장; 다중 프로젝트(Multi-profile) 탭 전환 및 서브에이전트(.claude/agents) 역할 배정 워크플로우 지원.
- Cons: 네이티브 모바일 앱(iOS/Android) 부재로 모바일 환경에서는 브라우저 접속에 의존; 멀티유저 권한 관리(RBAC)나 중앙 집중식 팀 협업 클라우드 동기화 기능 부재(로컬 파일 기반); 메인 리포지토리의 최근 커밋이 2025년 8월 하순 이후 둔화됨.
