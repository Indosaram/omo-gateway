### Happy (formerly Happy Coder / slopus/happy)
- URL: https://happy.engineering
- Kind: agent-native
- What: Happy is an open-source multi-provider agent harness and mobile/desktop client designed to orchestrate and control Claude Code, Codex, and Grok on user-owned hardware while reusing personal/work subscriptions. It provides continuous mobile monitoring, permissions approval, diff reviews, and session steering through an end-to-end encrypted relay.
- Agent integration: Native CLI wrapper and background daemon (`happy`, `happy claude`, `happy codex`, `happy agy`, `happy openclaw`, `happy acp <agent>`) supporting ACP (Agent Client Protocol) compatible agents; integrates Claude Code via Claude Agent SDK, Codex via ChatGPT OAuth/token-sharing, and Grok Build; supports tool extensions via MCP (Model Context Protocol) and Markdown/TOML skills; communicates with headless local daemon (`happy-agent`) over local socket and remote servers via WireGuard-based Tailcat tunnels or encrypted relay WebSockets.
- Mobile: Native iOS app available on Apple App Store (v1.8.0, 4.9 stars from 1k+ ratings, requires iOS 15.1+; developed with Expo/React Native in `packages/happy-app` and `packages/happy-ios`) and native Android app on Google Play Store (`com.ex3ndr.happy`, 5.0 stars from 3.1k+ reviews; `packages/happy-android`); also includes responsive web client at https://app.happy.engineering.
- Pricing: Core harness, desktop apps, CLI, and mobile clients are 100% free and open source with no seat licenses; users bring their existing Claude/ChatGPT/Codex/Grok subscriptions; optional built-in ElevenLabs conversational voice agent offers a free tier of 20 minutes per 30 days, followed by an in-app subscription ("Plus Plus Monthly" at $19.99/month on iOS for 5 hours per 30 days), or unlimited usage by bringing a personal ElevenLabs API agent at no additional charge.
- Self-host: Yes; full self-hosting supported via official Docker container (`packages/happy-server` / `packages/happy-server-self-host` using embedded PGlite, local storage, and optional Postgres/Redis/S3) for the zero-knowledge encrypted relay, as well as standalone headless daemon deployments (`happy-agent`) on Linux/macOS VPS or bare-metal servers connected over Tailcat WireGuard mesh.
- License: MIT License (across monorepo `slopus/happy`, `slopus/happy-desktop`, and `slopus/happy-agent`).
- Activity: 24,166 GitHub stars and 2,066 forks on `slopus/happy` (primary monorepo), 1,063 open issues, last pushed 2026-10-15; latest CLI release v1.2.5 published 2026-09-22; iOS App Store version 1.8.0 released 2026-10-07; highly active daily development across desktop, daemon, and mobile packages.
- Pros: True end-to-end encryption architecture (zero-knowledge relay server stores opaque blobs; master secret remains strictly on client devices); zero markup on model inference by reusing existing user subscriptions (Claude, Codex, Grok); native cross-platform mobile apps (iOS & Android) with live notifications, permission approvals, and colored diff viewers; robust headless daemon architecture allowing tasks to persist uninterrupted on servers or sleeping laptops; seamless subagent orchestration and team multiplayer mode with WorkOS authentication.
- Cons: Not a traditional kanban board (uses conversational session lists, project threads, and workspace tabs rather than cards/columns for task state tracking); requires local CLI setup and initial pairing dance via QR code between desktop/server and phone; voice feature is strictly metered (20 min free / $19.99/mo) unless self-provisioning an ElevenLabs agent; daemon management across reboot on macOS requires shell-init rather than standard launchd due to keychain permission constraints.
