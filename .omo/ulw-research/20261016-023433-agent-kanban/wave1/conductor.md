### Conductor
- URL: https://conductor.build
- Kind: agent-native
- What: A desktop and cloud orchestration platform by Melty Labs that runs parallel coding agents (Claude Code, OpenAI Codex, Cursor Agent, OpenCode) in isolated Git worktrees or cloud sandboxes. It provides a visual workspace board with real-time agent status, diff viewer, checks tab, terminal, and PR review workflow.
- Agent integration: Official hosted MCP server (`https://api.conductor.build/mcp`, tools include `create_workspace`, `list_project_workspaces`, `get_workspace_status`, `get_session_status`, `send_message`, `list_messages`, `cancel_session`, `run_sql`), REST API (`https://api.conductor.build/v0`), official CLI (`conductor`), and webhooks/routines; supported agents include Claude Code, Codex, Cursor Agent, and OpenCode.
- Mobile: Native iOS app available on Apple App Store (https://apps.apple.com/us/app/conductor-build/id6791228564, requires iOS 26.0+; released October 2, 2026 with v0.90.0, current v1.0.8); no native Android app listed; web app accessible via browser.
- Pricing: Free tier ($0 for local Mac workspaces, unlimited parallel local agents, BYO API keys/subscriptions); Pro tier ($50/user/month with Conductor Cloud hours, multiplayer up to 5 users, API access, iOS mobile app); Teams tier ($60/user/month with unlimited multiplayer, admin portal, centralized billing); Enterprise tier (custom pricing for SSO/SCIM, DPA, SLA, custom security).
- Self-host: Local-only files & local Mac desktop application by default; cloud workspace infrastructure runs in managed Vercel Linux sandboxes (us-east-1); self-hosted cloud sandboxes are not currently public (enterprise custom offering under active development per official FAQ).
- License: Proprietary (Melty Labs, Inc. / Melty, Inc. commercial software; not open source; terms of service grant non-exclusive client-side and hosted platform license).
- Activity: Active commercial product in rapid release (desktop v0.91.0 released Oct 15, 2026; iOS v1.0.8 released mid-Oct 2026; Melty Labs raised $22M Series A from Spark & Matrix in March 2026; desktop repo is closed source while Melty open-source editor has 5.5k stars).
- Pros: True Git worktree isolation preventing branch/file collisions across concurrent agents; Native multi-agent runner bundling first-class Claude Code, Codex, Cursor, and OpenCode; Rich status monitoring via desktop, native iOS mobile app, web dashboard, and MCP tools; Seamless workflow from issue triage to live diff inspection and GitHub PR opening; Zero-config local tier is completely free with BYOK privacy.
- Cons: Mac desktop application required for local mode (macOS only for local execution; no native Linux/Windows local app); Cloud sandboxes, API access, and mobile app require paid subscription ($50+/month); Closed-source proprietary core platform; Self-hosted private cloud sandboxes not yet generally available (in development for Enterprise); No native Android app available.
