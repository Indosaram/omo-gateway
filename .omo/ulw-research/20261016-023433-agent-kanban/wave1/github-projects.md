### GitHub Projects (v2)
- URL: https://github.com/features/issues
- Kind: general-kanban-with-agent-integration
- What: GitHub Projects (v2) is GitHub's native issue and project tracking system built directly into GitHub repositories and organizations, offering flexible Kanban boards, high-density tables, and roadmap timeline layouts connected directly to code, pull requests, issues, and draft tasks. It provides rich custom fields, automated status workflows, and tight permissions coupled with repository access controls.
- Agent integration: Official GitHub MCP Server (`@modelcontextprotocol/server-github` with Projects v2 support added Oct 2025/2026), community MCP servers (`arclio/github-projects-mcp`, `mcp-github-projects`), GitHub GraphQL API (`projectV2`, `ProjectV2Item`, `updateProjectV2ItemFieldValue`, `addProjectV2ItemById`), GitHub CLI (`gh project` command suite supporting create, edit, item-add, item-edit, item-archive, field-list), webhooks (`projects_v2_item` events); compatible with any agent capable of running CLI or MCP tools including Claude Code, Codex, Cursor, and OMO/Senpi.
- Mobile: Native iOS app (GitHub Mobile on Apple App Store) and native Android app (GitHub Mobile on Google Play Store) with full support for viewing and editing Projects (v2) boards, custom metadata fields, items, and status since general availability in March 2023; fully functional responsive mobile web is also supported.
- Pricing: Free tier includes unlimited public/private repositories and GitHub Projects with up to 50,000 items per project and up to 50 custom fields; Team plan is $4/user/month (or $3.67 billed annually); Enterprise plan is $21/user/month (annual billing/usage-based enterprise agreements) with advanced audit logs, compliance, and higher automation limits (as of October 2026).
- Self-host: Yes, via GitHub Enterprise Server (GHES) on-premises/private cloud (VM/hypervisor appliance including AWS, Azure, GCP, VMware), where Projects (v2) is included in modern GHES releases; not available as a standalone lightweight OSS Docker container.
- License: Proprietary (GitHub / Microsoft SaaS and GHES enterprise software license; official GitHub CLI and GitHub MCP servers are open-source under MIT license).
- Activity: Active core SaaS product by GitHub/Microsoft; official GitHub CLI (`cli/cli`) has over 36,000 GitHub stars with weekly releases; active updates across GitHub Mobile and GraphQL schemas throughout 2025-2026.
- Pros: Tightly integrated with GitHub repos, PRs, commits, and developer auth; First-class CLI (`gh project`) and GraphQL API make agent automation straightforward; Native mobile apps for iOS and Android allow checking agent task boards on the go; Generous free tier with support for up to 50,000 items per project; Support for lightweight 'Draft Issues' allows agents to log transient steps without cluttering the main issue tracker.
- Cons: Cannot be self-hosted without heavyweight GitHub Enterprise Server deployment; GraphQL API is required for programmatic access as Projects v2 is not fully exposed via classic REST endpoints; Webhook automation and complex state machines can have slight sync latency compared to local sqlite/memory boards; Project item queries require multi-step GraphQL node ID resolution which increases agent prompt/context overhead.
