### Crystal (stravu/crystal) / Nimbalyst
- URL: https://nimbalyst.com/ (formerly https://github.com/stravu/crystal, migrated to https://github.com/Nimbalyst/nimbalyst)
- Kind: agent-native
- What: Open-source visual workspace and multi-session AI code assistant manager built for parallel execution of Claude Code, OpenAI Codex, OpenCode, and Copilot. Provides dedicated session and task kanban boards, one-click git worktree isolation, inline WYSIWYG document/diagram/mockup editing, and real-time diff review.
- Agent integration: Official internal MCP servers running locally over HTTP/SSE (`/mcp/core`, `/mcp/host`, `/mcp/trackers`, `/mcp/situational`, `/mcp/extension-dev`), REST/WebSocket collab protocol (`wss://sync.nimbalyst.com`), CLI (`nim`, `nim wiki`), slash commands/skills (`/commit`, `/nimbalyst-wiki`), and native SDK integrations (`claude-agent-sdk`, `codex-sdk`); supports Claude Code, OpenAI Codex, OpenCode (alpha), GitHub Copilot (alpha), and Gemini. Agents push and read status directly via MCP tools (`tracker_create`, `tracker_update`, `tracker_list`, `tracker_link_session`, `update_session_board`, `update_session_meta`) and plain local markdown/JSON files.
- Mobile: Native iOS companion app (SwiftUI in repo at `packages/ios`, available via App Store / TestFlight) and native Android app (`packages/android` with Google Play Store release) alongside responsive web console (`console.nimbalyst.com`); enables push notifications when agents stall or request approval, text/voice prompt replies, and swipeable diff approvals.
- Pricing: Free and open source for individual local use with no feature limits or trial gates (users bring their own Claude Code / OpenAI API keys or subscriptions); Nimbalyst Teams collaboration tier priced at $20 per user per month (free during beta as of October 2026).
- Self-host: Yes; distributed as local desktop binaries (macOS .dmg for Apple Silicon and Intel, Windows .exe, Linux .deb and AppImage) built on Electron and TypeScript with local-first storage (SQLite/PGLite and plain Markdown files on disk); optional team collaboration uses Cloudflare Worker/Durable Object sync server (`nimbalyst-collab`).
- License: MIT License (both the desktop application and mobile companion apps).
- Activity: 3,132 stars on legacy `stravu/crystal` repo (deprecated/redirected February 2026) and 1,908 stars on active `Nimbalyst/nimbalyst` repo; active rapid releases (v0.81.6 pre-release pushed October 15, 2026).
- Pros: True agent-native design with dedicated session kanban and task tracking boards; Native one-click git worktree isolation preventing concurrent agents from stomping on shared worktrees; Visual WYSIWYG editors (Monaco, Lexical Markdown, Excalidraw, Mermaid, CSV) with interactive red/green diff reviews; Comprehensive internal MCP server architecture (`nimbalyst-trackers`, `nimbalyst-host`, etc.) giving agents native read/write status tools; Native iOS and Android companions supporting push notifications and remote prompt/approval workflows.
- Cons: Rebranding from Crystal to Nimbalyst creates legacy naming confusion; Team multiplayer features rely on external Cloudflare sync service rather than purely self-contained local LAN discovery; Heavy Electron desktop bundle compared to lightweight terminal multiplexers; Linux AppImage requires manual AppArmor profile setup on Ubuntu 24.04+; Advanced model integrations (OpenCode, Copilot ACP) remain in alpha status.
- Sources: https://github.com/stravu/crystal, https://github.com/Nimbalyst/nimbalyst, https://nimbalyst.com/, https://nimbalyst.com/features/session-management/, https://nimbalyst.com/features/task-management/, https://nimbalyst.com/kanban-for-claude-code/, https://nimbalyst.com/teams/, https://docs.nimbalyst.com/, https://api.github.com/repos/Nimbalyst/nimbalyst, https://api.github.com/repos/stravu/crystal
