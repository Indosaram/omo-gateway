### Coder Mux (Xum)
- URL: https://github.com/coder/mux (docs: https://mux.coder.com / https://xum.cdr.dev)
- Kind: agent-native
- What: An open-source desktop and headless multiplexer for parallel coding agents, offering isolated workspaces (worktrees, local, SSH, Docker), unified git status monitoring, sub-agent task coordination, and context compaction. Originally named Mux and renamed to Xum following a trademark request from Mux.com.
- Agent integration: Built-in native multi-agent engine supporting Anthropic (Claude 3.5 Sonnet, Claude 3.7 Sonnet, Opus 4), OpenAI (GPT-4o, GPT-5/o3), Grok, Ollama, and OpenRouter; provides Model Context Protocol (MCP) server support configured via `~/.xum/mcp.jsonc`; implements Agent Client Protocol (ACP) via `xum acp` for Zed, Neovim, and JetBrains; includes a VS Code / Cursor extension to inspect workspaces; exposes CLI via `xum run` / `@coder/xum` and a headless REST/WebSocket server via `xum server` (`~/.xum/config.json`).
- Mobile: Responsive web (no native iOS app, no native Android app, no PWA manifest; accessible on mobile browsers when running `xum server` via LAN/VPN with bearer token or GitHub device flow authentication).
- Pricing: Free and open-source (100% free; optional evaluation credits via Xum Gateway, or bring your own API keys for Anthropic, OpenAI, OpenRouter, or local Ollama).
- Self-host: Yes (self-hosted by design; distributed as pre-built standalone binaries for macOS, Linux, and Windows via GitHub Releases, installable via npm/npx as `@coder/xum`, or run locally as desktop app / headless background server `xum server`).
- License: GNU Affero General Public License v3.0 (AGPL-3.0).
- Activity: 2,055 GitHub stars (github.com/coder/mux / github.com/coder/xum); active daily development with latest release v0.31.1-nightly.479 on 2026-10-15 (stable v0.31.0 on 2026-10-09).
- Pros: True agent-native parallel workspace orchestration with automatic git divergence tracking; native support for local git worktrees, SSH remotes, Docker, and Coder environments; deep context management with opportunistic compaction, token budget sliders, and session memory; supports standard agent protocols (MCP tools and ACP editor bridges) alongside a companion VS Code / Cursor extension.
- Cons: UI focused on list/sidebar workspace multiplexing and chat timelines rather than classic horizontal Kanban columns; mobile experience is limited to responsive browser mode without native mobile push notifications; AGPL-3.0 license may constrain proprietary commercial redistribution; relatively young project (undergone a major rename from Mux to Xum).
- Sources: https://github.com/coder/mux, https://github.com/coder/xum, https://raw.githubusercontent.com/coder/mux/main/README.md, https://mux.coder.com, https://xum.cdr.dev/llms.txt, https://xum.cdr.dev/index.md, https://xum.cdr.dev/reference/cli.md, https://xum.cdr.dev/config/server-access.md, https://xum.cdr.dev/config/mcp-servers.md, https://xum.cdr.dev/integrations/acp.md, https://xum.coder.com/integrations/vscode-extension.md
- Confidence: high

### Coder Agents (formerly Coder Tasks)
- URL: https://coder.com/docs/ai-coder/agents (formerly Coder Tasks at https://coder.com/blog/launch-week-2025-introducing-coder-tasks)
- Kind: agent-native
- What: An enterprise-grade, self-hosted AI coding agent execution and orchestration control plane built into the Coder platform, allowing developers and teams to delegate tasks to autonomous coding agents running in isolated, governed infrastructure workspaces. Originally launched in July 2025 as "Coder Tasks" (`/api/v2/tasks`) and subsequently redesigned and graduated into "Coder Agents" / Chats API (`/api/v2/chats`).
- Agent integration: Standalone agent engine written in Go running inside the Coder control plane with sub-agent delegation, context compaction, and shell execution; provides Agent Relay for connecting external cloud-hosted agents (Cursor, Claude Code) to execute tool calls securely inside Coder workspaces; offers platform-level MCP server governance (`platform-controls/mcp-servers`); exposes full programmatic access via Coder CLI (`coder agent ...`), REST API (`/api/v2/chats`), and webhooks/CI integrations.
- Mobile: Responsive web (no native iOS or Android app; Coder web dashboard and agent chat/task interfaces are mobile-responsive web pages accessible over HTTPS/VPN).
- Pricing: Community tier is free (includes up to 5 concurrent active agents deployment-wide, unlimited runtime and tasks); Premium and AI Premium tiers are paid annually per user (custom/contact sales for enterprise pricing) with pooled "Agent Time" for unlimited concurrent agent scaling, SLA support, enterprise RBAC/OIDC, and advanced agent firewall/governance.
- Self-host: Yes (built to be deployed on Kubernetes via Helm, Docker Compose, or standalone Linux binary; integrates with Terraform-based Coder templates and enterprise infrastructure like AWS, GCP, Azure, OpenShift, and on-premise bare metal).
- License: Open-source core / Source-available (Coder core is AGPL-3.0 with enterprise proprietary extensions under Coder Enterprise/Premium license).
- Activity: 17,038 GitHub stars (github.com/coder/coder); actively maintained by Coder Technologies Inc. with frequent weekly releases in 2026.
- Pros: Complete enterprise governance with network-isolated sandboxes (nsjail, landjail, Docker, K8s) and agent firewalls; native Coder template integration allows exact baseline environments with all dependencies pre-installed; Agent Relay allows popular agents (Claude Code, Cursor) to execute safely on remote corporate infrastructure; Community tier includes 5 free concurrent agent slots with zero seat charges.
- Cons: Interface is a conversational task delegation and timeline monitoring UI rather than a drag-and-drop Kanban card board; setup requires deploying and managing a full Coder infrastructure control plane with Terraform templates; advanced security guardrails, audit logging, and unlimited concurrency require enterprise Premium licensing; Coder Tasks terminology was deprecated/removed in v2.34 in favor of the Chats/Agents model.
- Sources: https://coder.com/pricing, https://coder.com/pricing.md, https://coder.com/docs/ai-coder/agents, https://coder.com/docs/ai-coder/agents/licensing-usage, https://coder.com/docs/ai-coder/agents/tasks-to-chats-migration, https://coder.com/docs/ai-coder/agent-relay, https://coder.com/blog/launch-week-2025-introducing-coder-tasks, https://coder.com/blog/automate-coder-tasks-via-cli-and-api, https://github.com/coder/coder
- Confidence: high
