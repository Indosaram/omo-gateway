### Google Jules
- URL: https://jules.google (dashboard/web app: https://jules.google.com, docs: https://jules.google/docs/)
- Kind: agent-native
- What: Google Jules is an autonomous, asynchronous AI coding agent and task dashboard from Google Labs that executes bug fixes, documentation, feature development, and routine maintenance in isolated cloud VMs, presenting real-time progress, plan reviews, side-by-side diffs, and GitHub PR creation.
- Agent integration: REST API (official v1alpha at `https://jules.googleapis.com/v1alpha` supporting Sources, Sessions, and Activities with `X-Goog-Api-Key`), official CLI (`@google/jules` on npm with headless commands `jules remote new/list/pull` and an interactive terminal dashboard TUI), MCP server integration (official vetted MCP connections in Settings for services like Linear, Context7, Neon, Supabase, Stitch, and Tinybird as of February 2026), GitHub App / webhooks (triggers tasks automatically via the `jules` label on GitHub issues, acts on PR review comments and mentions, and automatically listens to and fixes failed GitHub Actions CI and Render preview deployment checks). Third-party external agents (Claude Code, Codex, Cursor, etc.) can programmatically push prompts, create sessions, query activity feeds/diff patches, and approve plans via the REST API or CLI scripts, but cannot be hosted directly as custom worker engines inside Jules.
- Mobile: responsive web (no native iOS or Android app listed in stores; web dashboard at `jules.google.com` uses responsive viewport metadata `<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1">` with browser push notifications for plan approvals and task completions, and changelog explicitly records mobile UI bug fixes)
- Pricing: Free tier available ('Jules' tier includes 15 tasks/rolling 24h, 3 concurrent tasks, powered by Gemini 3 Flash / 2.5 Pro; $0/month); Paid tiers accessed via Google One AI Plans (individual @gmail.com accounts only): 'Jules in Pro' via Google AI Pro plan (~$19.99/mo or ₩29,000/mo, 100 tasks/rolling 24h, 15 concurrent tasks, Gemini 3.1 Pro access) and 'Jules in Ultra' via Google AI Ultra plan (~$249.99/mo or ₩290,000/mo enterprise/ultra tiers, 300 tasks/rolling 24h, 60 concurrent tasks, priority Gemini 3/3.1 Pro access) [prices observed as of October 2026]
- Self-host: no (strictly a proprietary Google-hosted cloud SaaS; each session runs on Google-managed ephemeral Ubuntu Linux VMs with 20GB disk space and preloaded runtimes like Node.js, Bun, Python, Go, Java, Rust; no self-hosted Docker, on-prem, or local binary deployment exists)
- License: proprietary (Google Terms of Service; npm CLI package `@google/jules` is a closed binary distribution wrapper without open-source license)
- Activity: active (exited beta August 6, 2025; actively updated through 2026 with Gemini 3.1 Pro rollout March 9, 2026, CI auto-fixer and commit co-authoring February 19, 2026, and MCP server integrations February 2, 2026; companion prompt repository `google-labs-code/jules-awesome-list` has 100+ pull requests and active community commits)
- Pros: True autonomous execution in ephemeral cloud VMs with pre-installed multi-language runtimes (Node, Bun, Python, Go, Rust); Seamless GitHub integration with bi-directional issue labelling ('jules' label), PR comments, automated CI failure fixing, and commit co-authorship modes; Multi-surface interface offering both a rich web dashboard, interactive TUI, and fully scriptable REST API; Built-in Planning Critic agent and automated suggestions (Continuous AI for #TODO scanning and scheduled maintenance).
- Cons: Cloud-only proprietary Google SaaS with zero self-hosting capability; Paid tiers strictly tied to individual consumer Google One subscriptions (@gmail.com accounts only, blocking native Google Workspace / enterprise accounts without custom forms); Closed model selection restricted to Google Gemini family (no Anthropic Claude or OpenAI model support); MCP server support is currently curated/whitelisted by Google rather than arbitrary user-defined endpoints.
