### Backlog.md
- URL: https://backlog.md (GitHub: https://github.com/MrLesk/Backlog.md)
- Kind: agent-native
- What: A markdown-native task manager and Kanban visualizer built specifically for collaboration between humans and AI agents in Git repositories. It turns any folder or repo into a self-contained project board where tasks are stored as plain markdown files with YAML frontmatter, executable via CLI, terminal TUI, MCP server, and a local web interface.
- Agent integration: Official MCP server (`backlog mcp start`, using `@modelcontextprotocol/sdk`) preconfigured for Claude Code, OpenAI Codex, Gemini CLI, Kiro, and Cursor; CLI instructions via `backlog instructions overview` and automatic AGENTS.md / CLAUDE.md / GEMINI.md updates; stable JSON output mode (`--json` and `--json --watch`) for programmatic consumption and automation; no hosted REST/GraphQL API or external webhooks (operates directly on local Git/filesystem and local web server on 127.0.0.1).
- Mobile: Responsive web only (the local web UI launched via `backlog browser` is explicitly designed with responsive layout for desktop and mobile browsers, but binds to `127.0.0.1` by default requiring SSH tunnel/reverse proxy or LAN port binding to access from mobile devices); no native iOS app, no native Android app, and no standalone PWA installation manifest.
- Pricing: Free and 100% open-source ($0 / user / month; no paid tiers, no commercial licenses, no telemetry, no account required as of 2026-10-16).
- Self-host: Yes; entirely local-first and self-hosted by design. Runs locally via binary/CLI installed through npm (`npm i -g backlog.md`), Bun (`bun add -g backlog.md`), Homebrew (`brew install backlog-md`), or Nix flake (`nix run github:MrLesk/Backlog.md`). Web board runs via embedded local web server (`backlog browser`), can be run as a daemon service (systemd user unit, launchd plist, or Windows Task Scheduler/NSSM). No cloud server or external database dependency; all state is stored in repository markdown files (`backlog/tasks/*.md`).
- License: MIT License (https://github.com/MrLesk/Backlog.md/blob/main/LICENSE).
- Activity: Highly active open-source project; 7,044 GitHub stars, 449 forks, latest release v1.53.0 (released September 2026), latest repository commit pushed on 2026-10-15.
- Pros: 100% git-native and local-first with zero cloud lock-in (tasks live in version control alongside code); First-class MCP server and CLI instructions tailored for Claude Code, Codex, and Cursor workflows; Strict spec-driven review gates (spec review, plan review, code review) preventing agent drift; Zero-config lightweight setup with terminal TUI, live web Kanban board, and JSON watch streams; Cross-branch and worktree support with automatic cycle detection and acceptance criteria tracking.
- Cons: No multi-user real-time collaboration server or multi-tenant cloud sync (relies entirely on Git pull/push for multi-user coordination); No hosted mobile application or cloud notification system for mobile push alerts; Local web interface binds strictly to `127.0.0.1` requiring tunneling or service workarounds for remote viewing; Concurrency handling across concurrent writers in different processes is limited to file locks and fail-fast aborts.
