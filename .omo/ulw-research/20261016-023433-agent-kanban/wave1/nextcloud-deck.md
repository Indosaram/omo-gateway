### Nextcloud Deck
- URL: https://apps.nextcloud.com/apps/deck
- Kind: general-kanban-with-agent-integration
- What: Nextcloud Deck is an open-source, on-premise kanban-style task and project management app seamlessly integrated into the Nextcloud productivity platform. It provides boards, stacks (columns), cards with Markdown descriptions, labels, file attachments from Nextcloud Files, due dates, user assignments, and threaded comments.
- Agent integration: REST API (official OCS/REST API at `/index.php/apps/deck/api/v1.0` and `/ocs/v2.php/apps/deck/api/v1.0/` supporting full CRUD, board cloning, reordering, attachments, comments, and CalDAV synchronization); Community MCP servers available (notably `cbcoutinho/nextcloud-mcp-server` offering 15+ dedicated Deck MCP tools and `nc://Deck/boards` resources with token-efficient compact summaries, and `fastbs/mcp-nextcloud-deck` with stdio/streamable HTTP); CLI tools available (e.g. `ncdeck` in Go providing script-friendly `--json` commands and keyboard TUI, `nextcloud-cli` in Go, plus server-side `occ deck:*` commands); compatible with Claude Code, Cursor, Codex, OpenCode, and local coding agents via MCP config (stdio `uvx nextcloud-mcp-server` or HTTP) or direct REST/CLI calls.
- Mobile: Native Android app (official community app `nextcloud-deck` by Stefan Niedermann available on Google Play and F-Droid, GPL-3.0+); Native iOS app (`Next Deck` by Holger-Dev available on Apple App Store, Flutter-based, and third-party native client `Deckloud` on iOS App Store); Responsive web UI inside any mobile browser; Official Nextcloud mobile app handles system push notifications for Deck activities.
- Pricing: 100% free and open source for community self-hosting (unlimited users, boards, cards, no feature paywalls); Optional Nextcloud Enterprise support subscriptions start at €71.29/user/year (Standard, min 100 users = €7,129/year), €104.99/user/year (Premium), and €204.75/user/year (Ultimate) as of October 2026; Third-party clients like Deckloud offer free tier with optional one-time Pro purchase ($0 subscription).
- Self-host: yes (Self-hosted via Docker `nextcloud:latest`, Docker Compose, bare-metal PHP/web server, Kubernetes Helm chart, or Nextcloud AIO / All-In-One appliance; zero artificial self-hosting or enterprise restrictions on the Deck app itself).
- License: GNU AGPLv3 or later (GNU Affero General Public License v3.0+).
- Activity: ~3,000+ GitHub stars (repo `nextcloud/deck`), active commits in October 2026, latest stable releases v1.19.0 / v1.18.5 / v1.17.7 (October 2026) with development version 2.0.0-dev underway; ecosystem active with Android client updated October 2026 and MCP servers updated October 2026.
- Pros: Complete data sovereignty and self-hosting with no vendor lock-in or telemetry; Mature and well-documented REST/OCS API with rich community MCP and CLI tooling (`cbcoutinho/nextcloud-mcp-server`, `ncdeck`); Rich ecosystem with dedicated native mobile apps (Android F-Droid/Play Store, iOS Next Deck/Deckloud) and desktop clients; Deep integration with Nextcloud ecosystem (Files, Nextcloud Assistant AI, CalDAV calendar task delegation, user circles).
- Cons: Database performance bottlenecks reported on large instances with thousands of cards/attachments due to heavy relational queries; No native real-time WebSockets built into core Deck (relies on polling or Nextcloud `notify_push` high-performance backend); Out-of-the-box MCP server is community-maintained rather than first-party bundled by Nextcloud GmbH; Requires running and maintaining a Nextcloud server instance (PHP, DB, Web server) rather than a lightweight single-binary kanban.
