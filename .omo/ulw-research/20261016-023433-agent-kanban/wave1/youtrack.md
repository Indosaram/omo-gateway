### YouTrack (JetBrains)
- URL: https://www.jetbrains.com/youtrack/
- Kind: general-kanban-with-agent-integration
- What: A comprehensive project management and issue-tracking platform by JetBrains featuring agile/Kanban/Scrum boards, customizable workflows, Helpdesk, and Knowledge Base. It provides first-party built-in AI assistance and native Model Context Protocol (MCP) server endpoints alongside full REST APIs to allow external AI coding agents and human teams to coordinate tasks.
- Agent integration: Official native Remote MCP server built directly into YouTrack 2025.3+ at `https://<instance>.youtrack.cloud/mcp` (or self-hosted server equivalent) supporting OAuth 2.0 (with CIMD automatic registration) and permanent API bearer tokens; community local stdio/HTTP MCP server (`tonyzorin/youtrack-mcp` v2.0.0, MIT, Docker/npx); full REST API supporting JSON CRUD for issues, agile boards, custom fields, comments, articles, attachments, and time tracking; webhooks and workflow scripting engine (`@jetbrains/youtrack-scripting`); open-source CLI tools (`ryancheley/yt-cli`, `jetbrains-youtrack-cli`, `youtrack-app` CLI). Compatible with Claude Code, Claude Desktop, OpenAI ChatGPT/Agent Kit, Cursor, Codex, and custom AI agents.
- Mobile: Native iOS app (App Store id1028024655) and native Android app (Google Play com.jetbrains.youtrack.mobile.app; former React Native client at JetBrains/youtrack-mobile, now private Expo-based app); supports agile boards, issue updates, knowledge base, tickets, push notifications, offline draft caching, and dark/light modes; also accessible via responsive mobile web.
- Pricing: Free tier: Free forever for teams of up to 10 users and 3 Helpdesk agents on both Cloud and Server with full feature set and weekly replenished JetBrains AI credits. Paid Cloud (effective from Oct 1, 2025): starts at $5.40/user/month (monthly) or $4.50/user/month (annual, 2 months free), decreasing on volume tiers; additional Helpdesk agents at $6/agent/month (monthly) or $5.50/agent/month (annual). Paid Server: perpetual commercial user packs starting at $600/year for 15 users, 50% discount on support renewal within 12 months, and $72/agent/year for Helpdesk agents.
- Self-host: yes; available via official Docker container (`jetbrains/youtrack` on Docker Hub), ZIP/MSI installers for Linux and Windows Server, and JAR packages; free for up to 10 users with no feature restrictions; larger teams require perpetual user-pack licenses.
- License: Proprietary commercial license (JetBrains YouTrack Server Commercial License Agreement); free for up to 10 users, free 1-year renewable licenses for qualifying non-commercial open-source projects and classrooms.
- Activity: Active commercial product with regular releases (v2026.2 released in late 2026; major 2025.3 release introduced native Remote MCP); official mobile repo JetBrains/youtrack-mobile archived in favor of internal private Expo repo; community MCP `tonyzorin/youtrack-mcp` active (v2.0.0, 70+ stars, last updated mid-2025/2026).
- Pros: Built-in native Remote MCP server requiring zero local gateway or container setup for modern agents; Generous free tier for small teams (up to 10 users and 3 helpdesk agents forever on Cloud and Server); Full-featured self-hosting options via official Docker images with complete feature parity; Deep IDE and VCS integration with JetBrains ecosystem, GitHub, GitLab, and Bitbucket; Native mobile apps for iOS and Android with full agile board and ticket triage capabilities.
- Cons: Complex configuration and enterprise feature bloat for small automated agent fleets compared to lightweight markdown/sqlite boards; Proprietary core codebase preventing custom internal engine forks; Rate limits and weekly quotas on bundled JetBrains AI assistant credits require external AI keys or paid top-ups for heavy agent use; Mobile app requires public HTTPS or CA-signed certificates (self-signed certs rejected without custom root CA setup).
