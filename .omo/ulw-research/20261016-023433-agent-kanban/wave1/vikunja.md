### Vikunja
- URL: https://vikunja.io
- Kind: general-kanban-with-agent-integration
- What: Vikunja is an open-source, privacy-first task management and collaboration platform providing Kanban boards, Gantt timelines, table, and list views. Built in Go and Vue 3, it offers self-hosting as a single binary/Docker container and cloud-hosted tiers with built-in Model Context Protocol (MCP) support for AI agents.
- Agent integration: Official native MCP server built-in as of Vikunja 2.7.0 (endpoint at `/api/v2/mcp`, Streamable HTTP transport, token presets for read-only / typed tools / full access) with official integration guides for Claude Code (`claude mcp add --transport http --header 'Authorization: Bearer <token>' vikunja '<url>/api/v2/mcp'`), Codex CLI (`codex mcp add vikunja --url ...`), Claude Desktop, and Mistral Vibe (ChatGPT developer mode currently unsupported due to OAuth requirement); full REST API with v1 (legacy, deprecating in 3.0) and standard REST v2 (`/api/v2/` with OpenAPI 3.1 runtime specs, `PATCH` JSON merge patch, Bearer API tokens); webhooks with HMAC-SHA256 signatures for project and user events (`task.created`, etc.); community CLI and TUIs including `vja`, `tui-do` (local-first SQLite sync with quick-add CLI callable from agent scripts), and `cria`.
- Mobile: Responsive web with full PWA support (VitePWA/workbox service worker, web app manifest, mobile bottom sheet date picker added in 2.7.0); no official maintained native mobile app in Play Store / App Store (old Flutter app was deprecated/experimental); third-party native client exists for iOS/macOS: mDone (https://marco308.github.io/mdone/, open-source MIT on Apple App Store `id6760613430`, native SwiftUI with Kanban boards, widgets, offline sync, direct REST API connection).
- Pricing: Open-source free forever for self-hosting (all core task, kanban, gantt, table, team, caldav, and MCP features included); Vikunja Cloud managed hosting offers Personal at 4€/month (40€/year, 10GB storage), Family at 10€/month (99€/year up to 5 users), and Organization at 5€/user/month (50€/user/year, 50GB storage, priority email); Vikunja Pro self-hosted add-on (in private beta as of 2026-10-16) offers Homelab (flat fee up to 5 users), Team, Business, Scale, and Enterprise plans adding admin panel, audit logs, and time tracking on top of AGPLv3 core.
- Self-host: yes; single standalone binary (Go backend + embedded Vue frontend dist for Linux x86_64/arm64/armv7, macOS, Windows), Docker container (`vikunja/vikunja`, `ghcr.io/go-vikunja/vikunja`), Debian/Ubuntu APT repo, RPM (Fedora/RHEL/CentOS), Arch Linux (pacman), Alpine (apk), FreeBSD jail build, or Kubernetes; supports SQLite (bundled zero-config), PostgreSQL, MySQL, and MariaDB; zero enterprise restrictions on core self-hosting (Pro add-on in private beta only activates admin panel/audit logs/time tracking license key).
- License: AGPL-3.0-or-later (backend API and web frontend); GPL-3.0-or-later for optional desktop Electron wrapper in `desktop/`.
- Activity: 5,756 GitHub stars, 755 forks (GitHub `go-vikunja/vikunja`); active development (last release v2.7.0 on 2026-10-02, latest commit on main branch 2026-10-15); ongoing stable production status since 2018.
- Pros: Built-in native MCP server (`/api/v2/mcp`) with first-class connection guides for Claude Code, Codex, and Claude Desktop; True open-source (AGPLv3) self-hosting with zero-config single binary/Docker and bundled SQLite; Flexible multi-view support (Kanban with WIP limits and automated done buckets, Gantt, Table, List, and cross-project Saved Filters); Clean modern REST API v2 with complete OpenAPI 3.1 spec and webhook support for event-driven agent triggers; Rich ecosystem of companion tools including offline-first TUI (`tui-do`) and polished native iOS/macOS client (`mDone`).
- Cons: No official first-party native mobile app in Apple App Store or Google Play (relies on PWA, mobile browser, or third-party client mDone); ChatGPT Developer Mode integration currently blocked pending MCP OAuth implementation; Real-time updates via WebSockets are primarily internal state sync rather than fully exposed multi-agent collaboration subscriptions; Pro features (audit logs, central admin panel, time tracking) require a paid license key even though core task tracking remains completely free.
