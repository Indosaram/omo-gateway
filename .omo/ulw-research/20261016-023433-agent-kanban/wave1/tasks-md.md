### Tasks.md
- URL: https://github.com/BaldissaraMatheus/Tasks.md
- Kind: general-kanban
- What: A lightweight self-hosted Kanban task board that directly reflects a directory structure of Markdown files as lanes and cards. Built with SolidJS and Koa, it provides an Obsidian-friendly flat file workflow with zero database requirements.
- Agent integration: No official or community MCP server, CLI, or webhooks exist. However, AI agents (Claude Code, Codex, Cursor, etc.) integrate natively and seamlessly via direct filesystem operations: creating/moving `.md` files between lane subdirectories (e.g. `mv tasks/Todo/task-1.md tasks/Done/`) or reading/writing Markdown card bodies and inline metadata tags (`[tag:...]`, `[due:YYYY-MM-DD]`). Furthermore, the backend exposes an unauthenticated, lightweight REST HTTP API on port 8080 (`GET /_api/resource`, `POST /_api/resource/:path*`, `PATCH /_api/resource/:path*`, `DELETE /_api/resource/:path*`, `PUT /_api/sort/:path*`) that agents can query or manipulate with standard HTTP client tools without complex auth setup.
- Mobile: PWA and responsive web supported; no native iOS or Android app. The web UI is built with responsive layout and VitePWA plugin (`vite-plugin-pwa`) enabling home screen installation as a Progressive Web App, though PWA mode requires `BASE_PATH` to remain default (`/`).
- Pricing: Free and open-source (100% free; no paid tiers, no commercial licenses, no user seat limits as of 2026-10-16).
- Self-host: Yes; distributed primarily via a single Docker image (`baldissaramatheus/tasks.md` on Docker Hub with over 370k pulls) and docker-compose mounting `/tasks` and `/config` volumes, or runnable directly from source code using Node.js / npm with SolidJS frontend and Koa backend. No enterprise restrictions.
- License: MIT License (Copyright (c) 2023 Matheus Baldissara).
- Activity: 2,203 GitHub stars as of 2026-10-16; active maintenance with latest release v3.3.0 on 2026-03-08 (multilingual i18n support) and latest commit on 2026-03-08; active community PRs/issues through October 2026.
- Pros: Direct filesystem parity where lanes are subdirectories and tasks are plain `.md` files; zero external database or schema migrations needed, allowing instant zero-dependency interoperability with Obsidian and local agent file tooling; simple unauthenticated REST API and file format allowing trivial status tracking for coding agents; lightweight Docker footprint with minimal resource overhead; responsive interface with PWA support and customizable themes (Adwaita, Nord, Catppuccin).
- Cons: Lacks native real-time WebSockets or auto-refresh (file changes made by external agents outside web UI require manual browser reload or pending community auto-refresh patch PR #203); lacks built-in authentication, user management, or role-based access control (designed for single-user self-hosting or behind private reverse proxy); no official MCP server or pre-built webhook integrations for automated event streams; metadata like tags and due dates rely on simple regex bracket formatting (`[tag:...]`, `[due:...]`) directly prepended into Markdown text rather than formal YAML frontmatter.
