### Focalboard
- URL: https://www.focalboard.com
- Kind: general-kanban
- What: Open-source, multilingual project and task management tool created by Mattermost as an alternative to Notion, Trello, and Asana. It provides Kanban boards, tables, galleries, and calendar views for organizing cards and blocks, available as standalone desktop apps (macOS, Windows, Linux) and personal server (Docker/Ubuntu), but is no longer actively maintained by Mattermost and was transferred to community archive.
- Agent integration: REST API (standalone v2 API endpoints `/api/v2/boards`, `/api/v2/boards/{boardID}/blocks`, `/api/v2/cards`, authenticated via Bearer session tokens and custom headers `X-Requested-With: XMLHttpRequest`), no official MCP server (community scripts/webhooks only), no dedicated CLI (import scripts available for Notion/Trello/Asana), agents like Claude Code, Codex, or Cursor can interact via standard HTTP client calls to the REST endpoints.
- Mobile: responsive web only (standalone personal server web interface); no official standalone native iOS app or native Android app (desktop apps are macOS Mac App Store, Windows MSIX/Store, Linux desktop).
- Pricing: open-source free (free self-hosted desktop and server under AGPLv3 for source / MIT for compiled binaries; historically had a soft limit cloud check `boardsCloudLimits` of cards/views inherited from Mattermost Cloud).
- Self-host: yes (Docker image `mattermost/focalboard`, compiled binary `./bin/focalboard-server` on Ubuntu/Linux, local desktop SQLite apps on macOS, Windows, Linux; no enterprise license restriction on standalone version with `EXCLUDE_ENTERPRISE="1"`).
- License: GNU AGPL v3.0 (source code) / MIT License (compiled binary versions produced by Mattermost) / Apache 2.0 (admin tools, config files, client models).
- Activity: ~20,000+ GitHub stars; standalone repo archived/unmaintained by Mattermost (README notice: "This repository is currently not maintained. If you're interested in becoming a maintainer please let us know here" issue #5038; last standalone release v7.11.4 in July 2023 / v8.0.0 plugin transition in 2023–2024; repository moved under `mattermost-community/focalboard`).
- Pros: completely free and self-hostable with lightweight SQLite or MySQL backends; multi-view support including Kanban, Table, Gallery, and Calendar; full REST API with OpenAPI/Swagger specifications for card and block manipulation; desktop standalone builds allow zero-network local-first task tracking.
- Cons: standalone project is officially abandoned/unmaintained by Mattermost; no native mobile applications (iOS/Android) for standalone mode; no native MCP (Model Context Protocol) server or agent tool definitions; complex nested block architecture (`blocks`, `cards`, `contentOrder`) requires specialized payload construction for AI agents.
- Sources: https://github.com/mattermost/focalboard, https://raw.githubusercontent.com/mattermost/focalboard/main/README.md, https://raw.githubusercontent.com/mattermost/focalboard/main/CHANGELOG.md, https://raw.githubusercontent.com/mattermost/focalboard/main/LICENSE.txt, https://github.com/mattermost-community/focalboard/issues/5038
- Confidence: high

### Mattermost Boards
- URL: https://mattermost.com/marketplace/boards/
- Kind: general-kanban-with-agent-integration
- What: The integrated Boards plugin for the Mattermost enterprise collaboration platform (previously derived from Focalboard), offering channel-linked Kanban boards, task management, and team roadmaps embedded directly in Mattermost workspaces. It integrates with Mattermost's permission system, channel notifications, and the Mattermost Agents platform.
- Agent integration: REST API (`/plugins/focalboard/api/v2/*` including `/boards`, `/cards`, `/blocks`, and channel-linked endpoints authenticated via Mattermost Bot/User tokens), official Mattermost MCP Server via Mattermost Agents plugin (`mattermost-plugin-agents` v1.7.2+) allowing AI agents (Claude, ChatGPT, Claude Code, Cursor) to interact with workspace resources, webhook notifications on card changes, and `mmctl` CLI for server/plugin administrative automation.
- Mobile: native iOS app and native Android app via the official Mattermost mobile applications (App Store v2.44.1+, Google Play v2.44.1+; mobile support embeds channel boards and agent chat, though boards UI is optimized for web/desktop).
- Pricing: Included in Mattermost plans: Free Entry / Community tier (free self-hosted with limited cards/views and basic features); Professional plan (channel-centric collaboration, ~$10/user/month historically, currently custom/quote); Enterprise and Enterprise Advanced (air-gapped, zero-trust, full Work Management / Boards with unlimited cards, ABAC, and compliance; annual seat license subscription).
- Self-host: yes (self-hosted as a plugin on Mattermost Server via Docker, Kubernetes, Linux binary tarballs; full deployment on PostgreSQL/MySQL, air-gapped/offline installations supported).
- License: Mattermost Source Available License / GNU AGPL v3.0 / Apache 2.0 (plugin wrapper and core components under AGPLv3/Apache-2.0, enterprise compliance and ABAC modules under Mattermost commercial/source-available license).
- Activity: Active development in `mattermost/mattermost-plugin-boards` (Releases up to v9.4.0, v10.0.0 targeting Mattermost Server v12.0.0+ in 2025–2026; commits updated React 19 dependencies and security hardening in late 2025/2026).
- Pros: tightly integrated with Mattermost Channels, Playbooks, and Mattermost Agents AI platform; enterprise-grade role-based (RBAC) and attribute-based (ABAC) access controls; official MCP server enables external AI agents (Claude Code, Cursor) and internal bots to discover and manage workspace context; active maintenance and support for secure, air-gapped enterprise environments.
- Cons: requires a full Mattermost server deployment (not a standalone lightweight tool); advanced compliance, ABAC, and unlimited card limits require paid Enterprise/Enterprise Advanced tiers; Boards plugin UI is secondary to chat and primarily designed for desktop/web rather than full mobile kanban manipulation; API documentation is fragmented across Focalboard legacy swagger and Mattermost plugin routes.
- Sources: https://mattermost.com/pricing/, https://mattermost.com/blog/mattermost-mcp-server/, https://github.com/mattermost/mattermost-plugin-boards, https://github.com/mattermost/mattermost-plugin-agents, https://raw.githubusercontent.com/mattermost/mattermost-plugin-boards/master/README.md, https://raw.githubusercontent.com/mattermost/mattermost-plugin-boards/master/plugin.json
- Confidence: high
