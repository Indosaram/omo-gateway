### Plane
- URL: https://plane.so
- Kind: general-kanban-with-agent-integration
- What: Open-source, extensible project and knowledge management platform designed as an alternative to Jira and Linear for agile issue tracking, cycles (sprints), modules, wiki pages, and agentic workflows. It supports five core views (Kanban Board, List, Spreadsheet/Table, Calendar, and Gantt/Timeline) and positions itself as unified work infrastructure for humans and AI agents.
- Agent integration: Official open-source FastMCP server (`plane-mcp-server` on PyPI, v0.3.4 released October 9, 2026; MIT license) exposing 30 tools and 207 actions covering work items, cycles, modules, releases, pages, and PQL queries over stdio (local) or HTTP/SSE (OAuth/PAT at `https://mcp.plane.so/http/mcp`); first-class native client guides and configurations for Claude Code (`claude mcp add`), Codex (`~/.codex/config.toml`), Cursor (`cursor://` deep link and `~/.cursor/mcp.json`), VS Code Copilot Agent, Windsurf / Devin Desktop, Zed, and Google Antigravity; native Plane Agents Beta runtime (`AgentRun` / `AgentRunActivity` with `thought`, `action`, `response`, `elicitation`) triggered via `@agent` mentions, assignments, or webhooks; REST API v1 (`/api/v1/`) and v2 (`/api/v2/`) with PAT (`X-Api-Key`), HMAC-signed webhooks, typed SDKs (`@makeplane/plane-node-sdk`, `plane-sdk` on PyPI), and CLI (`prime-cli` / `plane compose`); native Cursor integration assigning tasks directly to Cursor AI to write code and open GitHub PRs.
- Mobile: Native iOS app on Apple App Store (v2.6.0 as of late September 2026, 116.3 MB, requires iOS 15.0+, supports iPhone, iPad, visionOS) and native Android app on Google Play Store (`com.plane.so`, requires Android 10+ / SDK 29+); connects to both Plane Cloud and self-hosted Commercial Edition (v1.5.0+); push notifications via APNs and FCM currently restricted to Plane Cloud; responsive web also available across desktop and mobile browsers.
- Pricing: Free tier: $0/user/month (up to 12 users, unlimited projects/work items, basic estimates/views, 5 layouts including Board/Kanban, intake); Pro tier: $8/user/month billed monthly or $6/user/month billed annually (unlimited seats, 500 AI credits/seat/mo, wiki, time tracking, custom properties, 1:5 guests); Business tier: $15/user/month billed monthly or $13/user/month billed annually (1000 AI credits/seat/mo, workflows + approvals, project templates, recurring items, intake forms/email, SAML/OIDC on self-hosted); Enterprise Grid: custom pricing (custom AI credit pool, SLA, granular access control GAC, LDAP, audit logs); Self-hosted Community Edition is 100% free under AGPL-3.0.
- Self-host: yes — Docker Compose, Docker All-in-One (AIO container for evaluation), Kubernetes Helm chart (`plane-enterprise` chart v3.9.0+), Podman Quadlets, Airgapped Edition, and managed 1-click PaaS (Coolify, Portainer, Zenith Hosting); Community Edition is fully self-hostable for free, while Commercial Edition self-hosting requires Pro/Business/Enterprise license keys for advanced features like native mobile app backend, SAML/OIDC, and God Mode instance admin.
- License: GNU Affero General Public License v3.0 (AGPL-3.0-only) for core Plane repository (`makeplane/plane`); MIT License for official MCP server (`makeplane/plane-mcp-server`); Commercial Edition extensions proprietary.
- Activity: GitHub repository `makeplane/plane` has ~61,000+ stars (61k badge on shields.io as of October 2026); active maintenance with version v1.4.2 released August 2026, v1.4.3-rc1 pre-release, and recent commits and PRs in October 2026; official MCP server (`plane-mcp-server`) active with release v0.3.4 on October 9, 2026.
- Pros: True open-source Jira/Linear alternative with strong self-hosting story via Docker and Kubernetes; First-class AI agent support with official 30-tool/207-action MCP server supporting Claude Code, Cursor, Codex, Windsurf, and VS Code out of the box; Flexible multi-layout system offering Kanban Board, List, Spreadsheet, Calendar, and Timeline with sub-grouping and PQL filtering; Integrated knowledge base (Pages/Wiki), sprint planning (Cycles/Modules), and issue intake (Forms/Email) alongside issue tracking; Native iOS and Android mobile apps supporting both cloud and self-hosted instances.
- Cons: Community self-hosted edition restricts mobile app login (requires Commercial Edition v1.5.0+ or Cloud); Push notifications on mobile apps are cloud-only and not supported on self-hosted instances; AGPL-3.0 copyleft license can be restrictive for commercial organizations seeking to embed or modify internal derivatives; Multi-container self-hosting architecture (PostgreSQL, Redis/Valkey, MinIO/S3, web, API, worker) requires substantial operational overhead compared to lightweight single-binary task boards.
