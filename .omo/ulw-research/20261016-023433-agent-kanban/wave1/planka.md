### Planka
- URL: https://planka.app (GitHub: https://github.com/plankanban/planka, Docs: https://docs.planka.cloud)
- Kind: general-kanban
- What: An open-source, real-time collaborative kanban board application built with React and Sails.js/Node.js, offering project and card tracking with custom fields, stopwatch time tracking, and markdown descriptions. While designed as a general-purpose team board, an active ecosystem of community MCP servers, REST APIs, and dedicated CLI/TUI tools has emerged to make it an effective dashboard for monitoring and driving AI coding agents.
- Agent integration: REST API (OpenAPI 3.0 / Swagger UI at `/api`, JWT and X-Api-Key authentication), Webhooks (100+ notification providers supported), dedicated CLI/TUI (`plnk` Rust CLI + `plnk-tui` real-time WebSocket terminal dashboard via https://github.com/plattnum/planka-cli with JSON schema output and AI agent handoff), Python SDK (`plankapy`), PHP SDK, and multiple community MCP servers including `@gogogadgetbytes/planka-mcp` (Claude Code / Claude Desktop / Cursor compatible via `npx @gogogadgetbytes/planka-mcp`), `kanban-mcp` (Cursor / Claude integration by bradrisse), `HexiDev/planka-mcp-kanban` (`npx planka-mcp`), allowing agents like Claude Code, Cursor, Codex, and custom AI agents to read boards, create/update cards, track task lists, post status comments, and move cards across columns.
- Mobile: Responsive web + PWA (web app manifest `manifest.json` with standalone display mode present in Community); dedicated mobile/tablet touch layout (swiping between lists/cards, finger drag-and-drop) is a commercial Pro 2.5.0+ feature; unofficial community native apps exist including a Flutter mobile app (`LouisHDev/planka_app` on GitHub with Android APK releases and iOS TestFlight) and an experimental companion Notes app (`planka-notes` on Android and iOS TestFlight); no official native app in Google Play Store or Apple App Store.
- Pricing: Community edition is 100% free for internal business, non-profit, personal, and educational self-hosting; commercial Pro Self-Hosted starts at €7.20–€7.90 per user/month (€36/month minimum 1 user, billed annually at €432/yr net excl. VAT as of October 2026); Pro Hosted starts at €8.50–€9.40 per user/month (€42.50/month minimum 5 users, billed annually at €510/yr net excl. VAT with 25GB storage); Enterprise plan available for 500+ hosted or 1,000+ self-hosted users with custom licensing and SLA; optional professional installation service from €469 + VAT.
- Self-host: yes (Docker and Docker Compose with PostgreSQL, Helm chart for Kubernetes, manual installation on Debian/Ubuntu/Windows with Node.js 24 and PostgreSQL; Pro edition requires an in-place migration adding Valkey and running `npm run db:promote`; license expiration locks Pro instances rather than downgrading to Community).
- License: Fair-code / Source-available under the "Fair Use License" (PLANKA Community License v1.1 based on n8n Sustainable Use License; allows personal, hobby, educational, and internal business use; prohibits white-labeling, commercial hosting for third parties, or charging third parties for access via API/service) and proprietary "PLANKA Pro/Enterprise License" for commercial versions.
- Activity: 12,619 GitHub stars (recorded 2026-10-16); latest release v2.2.1 on 2026-08-10 (security patch for CWE-22 path traversal); active commits in master branch as recent as 2026-09-17; actively maintained by PLANKA Software GmbH.
- Pros: Beautiful, lightweight, responsive Trello alternative with instant real-time synchronization; Complete OpenAPI 3.0 REST API with API key / JWT authentication and Swagger documentation; Rich AI agent ecosystem with ready-to-use MCP servers (`@gogogadgetbytes/planka-mcp`, `kanban-mcp`) and a dedicated scriptable Rust CLI (`plnk`) with JSON output; Zero license fees for self-hosted internal team and personal use; Built-in stopwatch time tracking, customizable fields, checklists, and webhook notifications.
- Cons: Non-OSI fair-code license restricts commercial multi-tenant hosting and SaaS redistribution; OIDC/SSO authentication was removed from Community in v2.2.0 and moved to paid Pro; Advanced touch/tablet optimizations, multi-board card mirroring, and calendar/timeline views are paywalled behind Pro; Official native mobile apps are missing from iOS App Store and Google Play (relying on PWA or third-party Flutter client); Pro upgrade is a one-way database migration that completely locks access if a commercial license expires.
