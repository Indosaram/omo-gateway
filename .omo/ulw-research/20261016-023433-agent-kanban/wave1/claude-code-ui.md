### Claude Code UI (CloudCLI)
- URL: https://cloudcli.ai
- Kind: agent-native
- What: A desktop and mobile web GUI/IDE originally created by Siteboon as Claude Code UI (claudecodeui, now rebranded to CloudCLI) for orchestrating and managing AI coding agent CLI sessions (Claude Code, Cursor CLI, Codex, OpenCode, Gemini CLI) across local and cloud environments. It features built-in chat, terminal (xterm.js), interactive file and git explorer, browser-use automation, and an integrated TaskMaster AI Kanban task board plus plugin architecture.
- Agent integration: Claude Code (via Claude Agent SDK & CLI ~/.claude sync), Cursor CLI, OpenAI Codex CLI/SDK, OpenCode, Gemini CLI; REST API (/api/agent, /api/taskmaster, /api/providers, /api/browser-use), WebSocket (/ws, /plugin-ws), MCP server management synced bidirectionally with local agent config (~/.claude/settings.json), TaskMaster AI CLI/MCP integration (task-master-ai CLI and .taskmaster/tasks/tasks.json storage), and ecosystem plugin integrations like claude-github-issue (/github-task skill) and cloudcli-plugin-task-queue (task-queue-mcp).
- Mobile: Responsive web application optimized for mobile touch navigation and mobile browsers; PWA-ready web interface with installable manifest and mobile layout; native companion desktop app available for macOS (DMG/menu bar) and Windows (NSIS tray), while dedicated native mobile iOS/Android apps are officially in development / planned ("A native app is also in the works").
- Pricing: Self-hosted open source is 100% free; CloudCLI Cloud hosted service offers Hobby at €7/month (1 environment, 2 vCPU, 4GB RAM, direct SSH), Growth at €20/month (5 environments, €5/mo extra), Team at €39/month (5 environments, 5 members, centralized billing, roles), and Custom Enterprise pricing (as of 2026-10-16). Users always bring their own LLM API keys / subscriptions (Claude, OpenAI, Cursor).
- Self-host: yes; run locally via npm/npx (`npx @cloudcli-ai/cloudcli` or `npm install -g @cloudcli-ai/cloudcli` requiring Node.js 22+), local Docker sandbox containers with microVM hypervisor isolation (`npx @cloudcli-ai/cloudcli@latest sandbox ~/my-project`), or self-hosted server deployment via PM2/systemd; optional local Electron desktop companion app for macOS/Windows.
- License: GNU Affero General Public License v3.0 or later (AGPL-3.0-or-later) with Section 7 additional terms (attribution to "CloudCLI UI", non-misrepresentation, trademark restrictions); relicensed by Siteboon AI B.V. on 2026-03-28 from GPL-3.0.
- Activity: ~14.1k GitHub stars (6.3k~14.1k recorded across repos/badges), latest release v1.37.4 on 2026-10-09, highly active development and frequent releases in 2026.
- Pros: Multi-agent CLI native support beyond Claude Code (Codex, Cursor, OpenCode); Built-in TaskMaster Kanban board with PRD parsing and task breakdown; Rich plugin architecture supporting custom tabs, external MCP task queues, and GitHub issue sync; Zero cloud lock-in with frictionless one-command local npx run; Clean responsive mobile web interface allowing monitoring and steering tasks from a phone.
- Cons: Native mobile apps for iOS/Android are not yet released (responsive mobile web / PWA only); AGPL-3.0 copyleft license imposes strict source disclosure if modified and hosted over a network; Advanced team sharing and zero-sleep persistence require the paid CloudCLI Cloud (€7-€39/mo) or custom VPS infrastructure; Initial tool execution permissions in Claude Code default to disabled for safety and require manual user activation; Heavy dependencies including Node.js v22+ and better-sqlite3 native bindings during server compilation.
