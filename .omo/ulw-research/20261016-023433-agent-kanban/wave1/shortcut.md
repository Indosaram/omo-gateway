### Shortcut
- URL: https://shortcut.com
- Kind: general-kanban-with-agent-integration
- What: Shortcut (구 Clubhouse)는 소프트웨어 엔지니어링 및 제품 개발 팀을 위한 이슈 트래킹 및 칸반/스프린트 프로젝트 관리 SaaS 플랫폼으로, 최근 AI 에이전트(Devin, Korey 등)와 인간 팀원이 함께 작업할 수 있는 'Shortcut for Agents' 및 공식 MCP 서버를 전면에 구축했습니다.
- Agent integration: 공식 호스팅 원격 MCP 서버(Streamable HTTP transport at `https://mcp.shortcut.com/mcp`, OAuth 인증), 오픈소스 커뮤니티/레거시 npm 패키지 `@shortcut/mcp` (GitHub `useshortcut/mcp-server-shortcut`), REST API v3 (`https://api.app.shortcut.com/api/v3`), Outgoing Webhooks 지원. Claude Code(`claude mcp add --transport http shortcut https://mcp.shortcut.com/mcp`), Cursor(`mcp.json` URL 연동), Windsurf, VS Code, Zed, Devin.ai 네이티브 연동 지원 및 전용 프로덕트 AI 에이전트 Korey(korey.ai) 지원.
- Mobile: 과거 React Native 기반 네이티브 iOS 앱(Clubhouse for iOS, App Store ID 1193784808) 및 Android 앱이 배포되었으나 현재 앱스토어 및 구글 플레이에서 내려간 상태(404 Not Found); 현재는 모바일 지원 공식 네이티브 앱 없이 모바일 반응형 웹(Responsive Web) 및 PWA 브라우저 접속으로만 이용 가능.
- Pricing: Free Plan: $0/사용자/월 (최대 10명 사용자, 1개 팀, 1개 워크스페이스, 칸반 보드, 로드맵, 기본 리포트, MCP Server 및 AI Agent 협업 지원 포함). Team Plan: $8.50/사용자/월 (무제한 사용자, 최대 5개 팀, WIP 제한, 자동화). Business Plan: $12/사용자/월 (무제한 팀/워크스페이스, 고급 커스텀 필드, OKR 연동). Enterprise Plan: 맞춤 견적 (SSO/SAML, SCIM, 전담 SLA, 250GB+ 저장공간). 비영리단체 100% 무료, 50인 미만 스타트업 12개월 무료 프로그램 운영 (2026-10-16 기준).
- Self-host: no (Shortcut 코어 플랫폼은 100% 클라우드 멀티테넌트 SaaS 전용이며 온프레미스/셀프호스트 미지원; 단, 레거시 오픈소스 MCP 서버 클라이언트는 로컬 Node/Bun 환경 또는 stdio 환경에서 npx 실행 가능).
- License: proprietary (Shortcut 코어 SaaS 플랫폼 및 호스팅 인프라는 독점 상용 라이선스; 공식 MCP 서버 저장소 `useshortcut/mcp-server-shortcut` 코드는 MIT License).
- Activity: Shortcut 플랫폼 자체는 매우 활발하게 운영 중이며 2026년 가을에도 지속적인 AI 에이전트 협업 기능 업데이트 진행 중; 반면 공식 GitHub 저장소 `useshortcut/mcp-server-shortcut`는 96 stars, 2026-07-08 v0.25.0 릴리스 이후 호스팅 서버(`https://mcp.shortcut.com/mcp`)로 개발이 일원화되면서 저장소가 공식 아카이브(Archived/Read-only) 처리됨 (npm `@shortcut/mcp` v0.25.0 배포 상태).
- Pros: 공식 호스팅 원격 MCP 엔드포인트(`https://mcp.shortcut.com/mcp`) 제공으로 토큰 관리나 별도 인프라 배포 없이 OAuth만으로 Claude Code/Cursor/Windsurf 즉시 연동 가능; Story/Epic/Iteration/Doc/Task/Custom Field/Label/Comment에 걸친 방대한 MCP 도구 세트 제공; Story마다 유효한 git 브랜치 이름을 생성(`stories-get-branch-name`)하거나 PR/커밋과 연계 가능; 10명까지 무료로 칸반/스프린트와 MCP를 제한 없이 사용 가능한 우수한 Free 티어; Devin.ai 네이티브 연동 및 제품 스펙 자동 작성 AI 에이전트 Korey 내장.
- Cons: 온프레미스/자체 호스팅(Self-hosting)이 불가능하여 폐쇄망 사내망 환경에 부적합; 네이티브 모바일 앱(iOS/Android)이 스토어에서 내려가 모바일에서의 사용성이 데스크톱 대비 떨어짐; GitHub 오픈소스 MCP 레포지토리가 아카이브되어 세부 MCP 구현 커스텀이나 온프렘 MCP 확장이 어려움; 분당 200회로 제한된 REST API 속도 한도(Rate Limiting 200 req/min)로 인해 대규모 다중 에이전트 동시 접근 시 Throttling 발생 가능성.
