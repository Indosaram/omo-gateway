### monday.com boards
- URL: https://monday.com
- Kind: general-kanban-with-agent-integration
- What: monday.com is an enterprise cloud work operating system featuring customizable boards, kanban views, table views, automations, and an integrated native AI layer. Teams and autonomous agents use boards to organize workflows, track task states via status columns, and coordinate multi-step projects.
- Agent integration: Official hosted Platform MCP server (`https://mcp.monday.com/mcp` via Streamable HTTP, supporting OAuth 2.1 or personal Bearer tokens), open-source local MCP package (`@mondaydotcomorg/monday-api-mcp` via npx/npm), official GraphQL platform API (`https://api.monday.com/v2`), official Go CLI `mcli` (`github.com/mondaycom/mcli` with JSON/LLM-native semantic layers and background webhook daemon), incoming/outgoing webhooks, and pre-approved third-party agent connectors (Claude Desktop, Claude Code, Cursor, ChatGPT, Microsoft Copilot / Copilot Studio, Mistral le Chat, Gemini CLI / Enterprise, Perplexity, Figma Make).
- Mobile: Native iOS app (iPhone & iPad available on Apple App Store, e.g. "monday.com: Work Management"), native Android app (available on Google Play Store), and mobile responsive web (cited in monday.com support documentation and pricing FAQ).
- Pricing: Free tier ($0 for up to 2 seats, up to 3 boards, 1,000 items, 500 MB storage, no automations/integrations); Basic ($9/seat/month billed annually or ~$12 billed monthly, min 3 seats); Standard ($12/seat/month billed annually or ~$14/month billed monthly, 250 automation/integration actions/month, 500 AI credits/month); Pro ($19/seat/month billed annually or ~$24/month billed monthly, 25,000 actions/month, private boards, 500 AI credits/month); Enterprise (custom pricing upon request, 250,000 actions/month, 25,000 daily API calls). monday dev pricing: Basic $9/seat/mo, Standard $12/seat/mo, Pro $20/seat/mo (annual). Verified October 2026.
- Self-host: no (strictly multi-tenant SaaS cloud service; no Docker, self-hosted binary, or on-premise deployment available, even for Enterprise tiers).
- License: proprietary (commercial closed-source SaaS; developer tools including `mcli` and the `@mondaydotcomorg/monday-api-mcp` wrapper are MIT licensed).
- Activity: Active commercial SaaS product (NASDAQ: MNDY). Supporting open-source agent tools on GitHub: `mondaycom/mcp` (430 stars, last commit October 15, 2026; npm package `@mondaydotcomorg/monday-api-mcp` v3.3.1) and `mondaycom/mcli` (created August 2026, Go CLI for LLM agents, last commit September 2026).
- Pros: Enterprise-grade hosted Platform MCP requiring zero local server setup; First-class agent tooling including `mcli` CLI with saved semantic queries/mutations and background webhook polling; Comprehensive 60+ MCP tools covering boards, items, columns, subitems, automations, and raw GraphQL fallback (`all_monday_api`); Native programmatic agent signup API with HATCHA solving and dedicated agent-tier rate limits (20M complexity points/min); Mature mobile apps across iOS and Android with real-time push notifications.

### monday AI Agents (Platform Agents)
- URL: https://developer.monday.com/api-reference/docs/build-on-monday-with-ai.md
- Kind: agent-native
- What: monday.com's native AI Agent platform allowing autonomous agent orchestration directly inside boards and workflows. Platform agents have assignable profiles, markdown execution plans, configurable triggers, tool skills, and board access permissions to monitor and update board tasks autonomously.
- Agent integration: Managed via Platform MCP tools (`manage_agent`, `manage_agent_triggers`, `manage_agent_skills`, `manage_agent_knowledge`, `agent_catalog`), preview GraphQL schema mutations (`create_agent`, `run_agent`, etc.), webhook triggers for custom external agents, and Anthropic Claude Managed Agents integration. External agents (Claude Code, Cursor, Codex) can manipulate and trigger these internal agents through the hosted Platform MCP server.
- Mobile: Native iOS and Android apps (embedded within the monday.com mobile app where agent updates appear in item activity streams and discussion threads) plus responsive web.
- Pricing: Requires a paid monday.com plan (Standard $12/user/mo, Pro $19/user/mo, or Enterprise) plus AI Credits consumption. Standard and Pro include 500 AI credits/account/month; additional credits are purchased as usage add-on packs (~800-1,200 credits/mo typical for a small team).
- Self-host: no (cloud-only managed execution within monday.com's infrastructure; external custom agents can be hosted anywhere and connected via webhooks).
- License: proprietary (cloud feature set of monday.com).
- Activity: Active beta/GA rollout as of late 2026 across monday Work OS; documentation and preview schemas actively updated in October 2026.
- Pros: Seamless native integration where AI agents participate as board assignees and commenters alongside human team members; Direct trigger hooks based on column changes, status updates, or schedules without third-party integration glue; Granular governance allowing admins to restrict agent knowledge and read/write scopes to designated boards/docs; Programmatic lifecycle control via Platform MCP tools; Supports both fully managed internal agents and external webhook-driven bots.
- Cons: Consumes proprietary AI credits on top of standard per-seat subscription tiers; Management API remains partially in preview/dev GraphQL schema; Cannot be run on-premise or disconnected from monday.com's cloud; Execution latency and debugging visibility are bounded by monday's proprietary runner; External webhook agents require hosting a separate public callback server.
- Sources: https://developer.monday.com/api-reference/docs/manage-agent.md, https://developer.monday.com/api-reference/docs/build-on-monday-with-ai.md, https://monday.com/pricing, https://developer.monday.com/api-reference/docs/mondaycom-mcp.md, https://developer.monday.com/api-reference/llms.txt
