### WeKan
- URL: https://wekan.fi
- Kind: general-kanban-with-agent-integration
- What: WeKan is an open-source, collaborative kanban and project management platform built on Meteor and Node.js that serves as a self-hosted alternative to Trello, Jira, and Asana. It provides real-time multi-view task management (swimlanes, lists, tables, calendar, Gantt, and version-control issue boards) with extensive import/export features and built-in automation rules.
- Agent integration: No official standalone MCP server shipped in core WeKan, but community MCP bridge workflows exist (e.g., n8n WeKan MCP server node supporting full card/list CRUD operations for Claude Code, Codex, and Cursor); native comprehensive REST API (token-based via `/users/login`, full CRUD for boards, lists, swimlanes, cards, attachments, and rules via `models/cards.js`); compatible REST API emulation layers added in v12.42 (Trello, Jira, GitHub, and Gitea API compatibility modes enabling agents and CLI tools targeting those ecosystems to speak to WeKan); incoming and outgoing webhooks (Slack/Mattermost/Discord compatible formats, global webhooks in Admin Panel); Python CLI client script (`api.py` in repo); bot execution integration in v12.43 ("Bots" mechanism to hand off board cards to external runner scripts, CI jobs, or AI agent workers without granting human account privileges).
- Mobile: PWA and responsive web; native wrapper apps available via Google Play Store (Trusted Web Activity / TWA full-screen browser wrapper for Android) and Ubuntu Touch OpenStore (Morph browser wrapper), while iOS relies purely on mobile Safari/Chrome responsive web and "Add to Home Screen" PWA shortcuts (no native Apple App Store binary; official docs cite App Store policy restrictions and recommend PWA).
- Pricing: 100% free open-source software (FLOSS under MIT license) for personal and commercial self-hosting; official hosted SaaS at WeKan Cloud (EU Finland) is available either free (with normal user app permissions) or 50 EUR/year (~$54/year, ~4.17 EUR/user-equivalent or flat instance pricing with full Admin Panel and custom domains); commercial priority support/custom feature development available at 100 EUR/hour or prepaid plans ranging from 500 EUR/year to 5,000 EUR/3-years (as of 2026-10-16).
- License: MIT License (permissive FLOSS, no proprietary open-core restrictions).
- Activity: ~19k GitHub stars (popular Trello alternative on GitHub under `wekan/wekan`); extremely active continuous release velocity (v12.48 released on 2026-10-15, v12.47 on 2026-10-15, v12.46 on 2026-10-14; daily commits by lead maintainer Lauri Ojansivu / xet7).
- Pros: Fully open source under MIT with zero feature paywalls or telemetry; versatile self-hosting packaging across Docker, Kubernetes, Snap, Sandstorm, Linux AppImage/binaries, and Windows bundles; supports embedded zero-config SQLite via FerretDB v1 alongside PostgreSQL and MongoDB; extensive multi-platform import/export (Trello, Jira, Linear, GitHub, Asana, Markdown, CSV, JSON); multi-ecosystem API compatibility (Trello/Jira/GitHub emulation modes) making AI agent drop-in connection straightforward; built-in IFTTT-style rule automations and webhooks.
- Cons: Mobile experience is purely a wrapped webview/PWA without offline sync or native OS integration; core architectural heritage on Meteor framework can lead to higher memory footprint (minimum 1GB RAM recommended, 4GB in production) compared to lightweight Go/Rust kanban alternatives; no first-party published npm/PyPI MCP package maintained directly by upstream WeKan core; real-time multi-user operations historically prone to race condition edge cases requiring frequent patch iterations.
- Sources: https://wekan.fi, https://github.com/wekan/wekan, https://wekan.fi/app, https://wekan.fi/saas/, https://wekan.fi/commercial-support/, https://github.com/wekan/wekan/blob/main/docs/API/REST-API.md, https://github.com/wekan/wekan/blob/main/docs/API/Cards.md, https://raw.githubusercontent.com/wekan/wekan/main/CHANGELOG.md, https://raw.githubusercontent.com/wekan/wekan/main/package.json
- Confidence: high (all fields verified against official repository codebase, live package.json, release tags, and official documentation as of 2026-10-16).
