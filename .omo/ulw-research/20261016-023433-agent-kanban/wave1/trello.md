### Trello (Atlassian)
- URL: https://trello.com
- Kind: general-kanban-with-agent-integration
- What: A widely adopted cloud kanban board tool organizing tasks into boards, lists, and cards with checklists, custom fields, and Butler no-code automation. Acquired by Atlassian in 2017 and recently integrated with Atlassian Intelligence and Model Context Protocol (MCP) bridges.
- Agent integration: Official remote MCP server hosted at `https://mcp.trello.com/v1` (supports OAuth 2.0, Claude, ChatGPT, Cursor, VS Code, Google Gemini CLI with `trello-use` agent skill), mature community local MCP server (`@delorenj/mcp-server-trello` on npm/MCP Registry with 57 tools supporting Claude Code, Cursor, Codex via API key/token), comprehensive REST API (`https://api.trello.com/1/` with webhooks, token bucket rate limits of 300 req/10s per API key and 100 req/10s per token), and community CLIs/Butler automations.
- Mobile: Native iOS app (App Store: "Trello: Manage Anything", requires iOS 18.6+ / iPadOS 18.6+ / visionOS 2.6+, offline sync support, widgets, v2026.21 as of Oct 2026); native Android app (Google Play: "Trello: Personal Planner App", offline sync, widgets); mobile responsive web (`https://trello.com`).
- Pricing: Free tier ($0 for up to 10 collaborators per Workspace, unlimited cards, up to 10 boards/workspace); Standard plan at $5/user/month billed annually ($6 monthly) adding unlimited boards, custom fields, card mirroring; Premium plan at $10/user/month billed annually ($12.50 monthly) adding dashboard/timeline/table/calendar views, AI features, and admin controls; Enterprise plan at $17.50/user/month billed annually ($210/year/user) including Atlassian Guard Standard security and 24/7 admin support (verified October 2026).
- Self-host: no (cloud SaaS only hosted by Atlassian; no official Docker container, binary, or self-hosted package exists).
- License: proprietary (SaaS; official MCP repository is Apache 2.0, community MCP servers are MIT).
- Activity: Active SaaS service operated by Atlassian (over 50M registered users); official MCP repo `atlassian/trello-mcp-server` actively maintained (Apache 2.0); community MCP `@delorenj/mcp-server-trello` v0.3.x actively maintained with MCP Registry listing; iOS app updated 2 days prior to October 2026 (v2026.21).
- Pros: Extremely simple, intuitive visual kanban model that human managers and AI agents understand with zero learning curve; First-class official remote MCP endpoint (`https://mcp.trello.com/v1`) plus feature-rich community MCP servers for Claude Code/Cursor/ChatGPT; Generous free tier suitable for solo developers and small agent experiment teams; Native mobile apps for iOS and Android with solid offline synchronization; Real-time webhooks and extensive REST API for bi-directional event reaction.
- Cons: Cloud SaaS only with zero self-hosting capability, problematic for air-gapped or sensitive corporate agent data; Official cloud MCP currently limited to a single workspace per connection at launch and lacks direct comments/attachments tools (though community MCP covers this); Free tier caps collaborator limits (10 per workspace) and lacks custom fields; Strict API rate limits (100 requests per 10s per token) can throttle high-frequency multi-agent swarms without batching.
