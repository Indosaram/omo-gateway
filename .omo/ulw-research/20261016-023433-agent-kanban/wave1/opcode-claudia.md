### opcode (formerly Claudia, getAsterisk, Gooey)
- URL: https://github.com/winfunc/opcode (formerly github.com/getAsterisk/claudia, github.com/getAsterisk/gooey, https://claudia.so, https://asterisk.so)
- Kind: agent-native
- What: A high-performance open-source GUI desktop application and web server toolkit designed for Claude Code, allowing developers to create custom AI agents, manage interactive sessions, explore projects, inspect timelines with branching checkpoints, manage MCP servers, and track token/cost analytics. Originally launched as Claudia (and Gooey) by Asterisk (winfunc), it is built with Tauri 2, Rust, React 18, and Axum.
- Agent integration: Claude Code (native CLI integration via `claude` executable, scanning `~/.claude/projects/`, session resume/execution, and `CLAUDE.md` editor); custom CC Agents architecture (system prompts, icon presets, model selection across Claude 3.5 Sonnet, Claude 3 Opus, Haiku, background process isolation, and exportable `.opcode.json` specs); MCP server manager executing `claude mcp add/list/get/remove` and syncing with Claude Desktop / `.mcp.json`; REST API & WebSocket server (`opcode-web` on port 8080) exposing `/api/projects`, `/api/projects/{id}/sessions`, `/api/agents`, `/api/usage`, `/api/mcp/servers`, and `/ws/claude` for remote agent session control; extensible to Cursor/Codex/CCR via custom execution commands.
- Mobile: Responsive web application via built-in `opcode-web` server mode (accessible over local network/VPN at `http://<host>:8080` with mobile-optimized layout, touch events, and WebSocket streaming); no native iOS or Android app listed in App Store/Play Store (Tauri mobile targets not officially published).
- Pricing: 100% free and open-source (no subscription fees, no paid tiers, zero commercial gatekeeping); users bring their own Anthropic Claude API keys or Claude Code subscription credentials.
- Self-host: yes; local desktop binary (macOS DMG/universal, Linux .deb/.AppImage, Windows .msi/.exe via Tauri 2 and Rust), source build (`bun install && bun run tauri build`), or headless/self-hosted web server binary (`opcode-web` via Axum/Tokio with REST & WebSocket endpoints).
- License: AGPL-3.0 (GNU Affero General Public License v3.0, verified in LICENSE file).
- Activity: 22,400+ GitHub stars; 1,700+ forks; 267 open issues; 65 PRs; actively maintained under winfunc (latest commit d1ca30a in September 2026, web server mode and HTTPS WSS fixes in late 2025/2026).
- Pros: Beautiful and fast native desktop UI built on Tauri 2 and Rust; CC Agents library with ready-to-use bots (Git commit bot, SAST security scanner, unit test bot); deep timeline checkpointing with branching, diff viewer, and instant restore; built-in web server mode (`opcode-web`) allowing phone/browser remote control; full local privacy with local SQLite storage, no mandatory telemetry, and direct MCP configuration.
- Cons: No native mobile apps in App Store/Play Store (relies on web mode over LAN/tailscale); pre-built release binaries have experienced delays (users frequently build from source via Bun and Rust); tightly coupled to Anthropic's Claude Code CLI ecosystem rather than generic multi-agent protocols; project renaming (getAsterisk/claudia -> gooey -> opcode -> winfunc/opcode) has caused scattered community documentation.
