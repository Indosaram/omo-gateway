### Gitea
- URL: https://about.gitea.com/
- Kind: general-kanban-with-agent-integration
- What: Gitea is an open-source, lightweight self-hosted DevOps and Git service written in Go, featuring built-in issue tracking with multi-column project kanban boards at user, repository, and organization levels.
- Agent integration: REST API with complete OpenAPI v1 spec (`/api/v1/repos/{owner}/{repo}/projects`, `.../columns`, `.../columns/{column_id}/issues/{issue_id}`, and move endpoints), Webhooks, official CLI `tea` (v1.0 requiring Gitea 28+), and multiple community MCP servers (`@williamking/gitea-mcp`, `@echo-note/gitea-toolkit-mcp`, `gitea-mcp-tool`, `@ric_/forgejo-mcp`) allowing agents like Claude Code, Codex, Cursor, and Continue to create projects, list columns, add tasks, and move issue cards across kanban columns.
- Mobile: Responsive web (native mobile browser UI with responsive layouts and PWA manifest support), no official first-party mobile app for iOS or Android, but well-maintained third-party native apps exist (most notably GitNex for Android on Google Play and F-Droid, GPLv3).
- Pricing: Open Source edition is 100% free and self-hosted with unlimited users and repositories; Gitea Enterprise self-managed subscription starts at $9.50/user/month (with annual commitment, standard $19/user/month) providing SAML SSO, audit logs, and priority SLA support (as of 2026-10-16).
- Self-host: yes; single self-contained binary (Go), official Docker/Podman container images, Helm charts for Kubernetes, and packages for major Linux distributions; no feature paywalls on core kanban project boards.
- License: MIT License (Open Source core); Gitea Enterprise has proprietary enhancements and support contracts managed by Gitea Ltd.
- Activity: ~59k GitHub stars (go-gitea/gitea); active development with latest release v28.1.0 released on 2026-10-06.
- Pros: Extremely lightweight and resource-friendly (runs effortlessly on low-spec VPS or Raspberry Pi); Comprehensive REST API covering complete project board lifecycle (creating boards, custom columns, moving issues between columns); Zero cost for full kanban capability with MIT license and no user seat limits; Growing ecosystem of community MCP servers and CLI automation tools; Can unify code repositories, git actions, issue tracking, and agent kanban in a single self-hosted infrastructure.
- Cons: Kanban boards are traditional issue trackers rather than agent-native execution graphs (lack built-in agent stream logs, step status chips, or prompt traces out of the box); No official first-party mobile app (must rely on mobile browser or third-party GitNex); Open-core tension exists following Gitea Ltd's commercialization in 2022 (enterprise features reserved for paid tiers); Real-time board updates require manual page refresh or custom polling/websockets as boards lack native collaborative live websocket pushing for card drags.

### Forgejo
- URL: https://forgejo.org/
- Kind: general-kanban-with-agent-integration
- What: Forgejo is a 100% community-driven, non-profit soft-and-now-hard fork of Gitea stewarded under Codeberg e.V., providing fully free software forge capabilities including issue kanban boards for tracking development tasks.
- Agent integration: Fully backward-compatible Gitea REST API (`/api/v1/repos/{owner}/{repo}/projects`, columns, and issue movement), Webhooks, CLI support via `tea` and unofficial `forgejo-cli` / `bst-fj`, and community MCP servers (`@ric_/forgejo-mcp` with 457 tools, `@wyattjoh/forgejo-mcp`, `pi-forgejo-mcp`) compatible with Claude Code, Cursor, Codex, and MCP clients for programmatically managing kanban cards and progress.
- Mobile: Responsive web with built-in dark/light themes (`forgejo-dark`, `forgejo-light`) and PWA web app manifest (`/manifest.json`); no official first-party iOS/Android app, fully supported by the open-source native Android client GitNex (GPLv3 on F-Droid and Play Store).
- Pricing: 100% free open-source software (gratis and libre) with no enterprise tiers, no paywalled features, and no user limits; funded via donations and grants through Codeberg e.V. (as of 2026-10-16).
- Self-host: yes; standalone binary (Linux/BSD, Windows support dropped in 2024), official OCI/Docker container images (`codeberg.org/forgejo/forgejo`), and community Helm charts; zero enterprise-only restrictions.
- License: GNU General Public License v3.0 or later (GPL-3.0-or-later) starting with Forgejo v9.0+ (versions up to v8.0 were MIT).
- Activity: 5,654 stars on Codeberg (forgejo/forgejo); extremely active with latest major release v17.0.0 released on 2026-10-15 and maintenance releases v16.0.6 / v15.0.10 on 2026-10-12.
- Pros: True non-profit community governance under Codeberg e.V. with strict commitment against open-core monetization or venture capture; Complete feature parity with Gitea project boards without artificial paywalls; Full REST API enables agents to create, inspect, and update kanban columns and cards; Copyleft GPLv3+ guarantees long-term openness and independence; High release cadence with thorough end-to-end and accessibility testing.
- Cons: Project boards remain conventional human-centric agile/kanban boards lacking native AI agent instrumentation (no token metrics, agent session attachment, or live terminal outputs); No first-party native mobile application; Dropped official support for hosting server binaries on Microsoft Windows OS in 2024; Hard-fork divergence from Gitea means upstream Gitea Enterprise plugins and third-party tooling may slowly develop incompatibilities over time.
- Sources: https://forgejo.org/, https://forgejo.org/faq/, https://forgejo.org/compare-to-gitea/, https://codeberg.org/forgejo/forgejo, https://codeberg.org/api/v1/repos/forgejo/forgejo/releases, https://codeberg.org/gitnex/GitNex, https://codeberg.org/
