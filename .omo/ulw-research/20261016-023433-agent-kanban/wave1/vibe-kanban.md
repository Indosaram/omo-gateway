### Vibe Kanban
- URL: https://www.vibekanban.com/ (Docs: https://vibekanban.com/docs, GitHub: https://github.com/BloopAI/vibe-kanban)
- Kind: agent-native
- What: A kanban-based developer platform built specifically to orchestrate, plan, review, and execute coding agent runs (Claude Code, OpenAI Codex, Gemini CLI, etc.) in isolated Git worktrees.
- Agent integration: Official local Model Context Protocol (MCP) server launched via `npx vibe-kanban --mcp` exposing stdio tools (`list_issues`, `create_issue`, `update_issue`, `start_workspace`, `run_session_prompt`, `get_execution`, etc.); CLI launcher (`npx vibe-kanban`); REST API on local/cloud backend; direct support for 10+ coding agents (Claude Code, OpenAI Codex, Google Gemini CLI, GitHub Copilot CLI, Amp, Cursor Agent CLI, OpenCode, Factory Droid, CCR/Claude Code Router, Qwen Code).
- Mobile: Responsive web only via Vibe Kanban Cloud / Remote Access (paired via host pairing code at `cloud.vibekanban.com` or self-hosted tunnel); no native iOS app, no native Android app, and no official standalone PWA packaging documented.
- Pricing: Free & open-source for local usage; previously offered Vibe Kanban Cloud subscriptions (which failed to find a viable business model with the vast majority being free tier users); company shut down on 2026-04-10, all recent subscriptions refunded, and product transitioned to 100% free community open-source.
- Self-host: yes — local desktop app / CLI run via `npx vibe-kanban` (local SQLite database); full remote cloud server self-hostable via Docker Compose (`docker-compose.prod.yml` with Rust `remote` backend, PostgreSQL 16 with logical replication, ElectricSQL, and Caddy reverse proxy; supports bootstrap single-admin auth or GitHub/Google OAuth).
- License: Apache License 2.0 (Apache-2.0).
- Activity: 28,376 GitHub stars; latest release v0.1.44 (2026-04-24); status is sunsetting as a commercial product / bloop shutdown announced on 2026-04-10, continuing as community-maintained open source.
- Pros: True agent-native Git worktree isolation preventing merge and dirty working tree conflicts across parallel agents; built-in diff review and inline commenting directly piped back into agent chat context; first-class MCP server support allowing external or internal agents to programmatically create issues and trigger workspace executions; multi-agent support across 10+ popular coding agent CLIs.
- Cons: Company Bloop AI shut down in April 2026 leaving future maintenance to open-source volunteers; rapid breaking changes in upstream agent CLIs require ongoing community updates; hosted cloud service deprecated requiring self-hosting or fully local setup; tightly coupled to coding/git workflows rather than general project management.
