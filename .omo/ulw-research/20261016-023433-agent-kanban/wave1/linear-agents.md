### Linear (Linear for Agents)
- URL: https://linear.app (and https://linear.app/developers/agents)
- Kind: general-kanban-with-agent-integration
- What: Purpose-built issue tracker, project management, and kanban system designed for high-velocity software product development. It features a dedicated Agent Platform where AI agents exist as distinct first-class workspace participants with delegation sessions, activity streaming, plan tracking, and MCP integration.
- Agent integration: Official hosted MCP server (`https://mcp.linear.app/mcp` via Streamable HTTP with OAuth 2.1 / API keys, plus read-only endpoint `/mcp/readonly` and legacy SSE at `/sse`), GraphQL production API (`https://api.linear.app/graphql`), official TypeScript SDK (`@linear/sdk`), webhooks with dedicated `AgentSessionEvent` / `AppUserNotification` / `PermissionChange`, and CLI via community/npm (`linear-release`, `@linear/cli` ecosystem). Supports native delegations and bidirectional interactions for Claude Code, Codex Cloud Tasks, Cursor, Devin (Cognition), GitHub Copilot coding agent, v0 by Vercel, Windsurf, Jules, and custom agents built on Claude Managed Agents or custom MCP/webhooks.
- Mobile: Native iOS app and native Android app built with native Swift and Kotlin ("Linear Mobile" companion app, cited from https://linear.app/mobile), plus responsive web app.
- Pricing: Free tier ($0, unlimited members, 2 teams, 250 issues, Agent platform & Linear Agent included); Basic tier ($10/user/month billed yearly, 5 teams, unlimited issues); Business tier ($16/user/month billed yearly, unlimited teams, private teams, Loops, Triage Intelligence, Code Intelligence); Enterprise tier (custom annual pricing, SAML/SCIM, HIPAA BAA). AI agent coding sessions and Loops use consumption-based AI credits (as of 2026-10-16). Installed app agents do not count as billable workspace users.
- Self-host: no (strictly cloud-hosted SaaS managed by Linear Orbit, Inc. with data residency options in US or EU; no self-hosted Docker/binary offered; enterprise customers remain on cloud with SAML/SCIM/HIPAA controls).
- License: proprietary (SaaS service and web client are proprietary commercial software; client SDK `@linear/sdk`, codegen, importers, and sample agent bridges like `claude-managed-agents-demo` and `weather-bot` are open-source under the MIT License).
- Activity: Active commercial product with over 40,000 corporate customers; SDK monorepo (github.com/linear/linear) has 1.6k+ stars, active commits and releases in 2026 (v98.0.0+ released October 2026 with AgentSession CodingHarness and elicitation updates).
- Pros: First-class Agent Platform treating agents as non-billable workspace delegates rather than replacing human assignees; Official remote MCP server natively usable across Cursor, Claude Code, Codex, Windsurf, and VS Code; Rich Agent Session lifecycle tracking states (pending, active, awaitingInput, complete, error, stale) with real-time thought/action/plan streaming; Fast native mobile apps for iOS and Android with triage, updates, and issue management; Built-in Loops automation and Coding Sessions that spin up Claude/Codex cloud harnesses to open verified PRs from kanban issues.
- Cons: Cloud-only SaaS with zero self-hosting capability for strict air-gapped on-premise environments; Full automation features like Loops and Coding Sessions require paid plans and consume metered AI credits; Hard 10-second requirement for agents to emit initial thought activities or risk being marked unresponsive; Rate limits and webhook timeouts (5s webhook response deadline) require persistent bridge servers for heavy external agents; Kanban board views are opinionated and tightly coupled to Linear's sprint/cycle and project structure rather than freeform custom boards.
