### Todoist

It pairs polished cross-platform applications with native agent support including an official hosted MCP server, developer SDKs, and a dedicated CLI.

Prices current as of October 2026.
- Self-host: no (Proprietary cloud SaaS; local offline cache in native apps but server and database run exclusively on Doist infrastructure).
- License: Proprietary (Apps & Backend SaaS); Open-source developer tools (MCP server `@doist/todoist-mcp` is MIT, CLI `@doist/todoist-cli` is MIT, Python SDK is MIT, TypeScript SDK is MIT).

- Pros: First-class agent support with official hosted Streamable HTTP MCP (`ai.todoist.net/mcp`) and zero-config OAuth/PKCE; Dedicated official CLI (`td`) with native skill installers for Claude Code, Codex, and Cursor; Clean Kanban board view with section columns available across free and paid tiers on both desktop and mobile; Mature offline synchronization and instant cross-device updates; High-quality developer documentation, OpenAPI specs, and Sync API batching.

### TickTick
- URL: https://ticktick.com
- Kind: general-kanban-with-agent-integration
- What: TickTick is an all-in-one personal productivity platform featuring GTD tasks, Kanban board views, calendars, habit tracking, and Pomodoro focus timers across desktop and mobile devices. It provides flexible column-based visual project management with drag-and-drop task progression.
- Agent integration: Community MCP servers (`dev-mirzabicer/ticktick-sdk` providing 43 MCP tools with FastMCP and async Python SDK, `liadgez/ticktick-mcp-server` Node/Docker MCP server with local task cache, and `alexarevalo9/ticktick-mcp-server`), official REST Open API v1 (OAuth2 at `developer.ticktick.com` for tasks/projects), unofficial reverse-engineered V2 session web API (for Kanban columns, folders, tags, habits, and focus tracking), compatible with Claude Code, Cursor, Claude Desktop, and custom LLM agents; no official first-party MCP server from TickTick.
- Mobile: Native iOS app (App Store, iPhone, iPad, Apple Watch, interactive widgets) and native Android app (Google Play, Android tablets, Wear OS, widgets), responsive web app, native desktop apps (macOS, Windows, Linux).
- Pricing: Free tier ($0, basic tasks, Kanban board view on custom lists, basic reminders); Premium plan ($3.99/month or $35.99/year ~$2.99/month, unlocks full calendar views, timeline view, custom smart lists, advanced Kanban features, revision history, and higher list limits). Prices current as of October 2026.
- Self-host: no (Proprietary cloud SaaS operated by Appest Inc., supporting global sync via TickTick and China sync via Dida365; local client cache in apps but no self-hosted backend).
- License: Proprietary (Cloud service and official client apps); Community MCP servers and SDKs (`ticktick-sdk`, `ticktick-mcp-server`) are MIT licensed open source.
- Activity: Actively maintained SaaS service; community MCP development is active (`ticktick-sdk` on PyPI updated late 2025/2026 supporting Python 3.11+ and FastMCP, `liadgez/ticktick-mcp-server` targeting Claude Code).
- Pros: Complete GTD ecosystem integrating Kanban boards, calendar time-blocking, habits, and Pomodoro timers in one app; Affordable premium subscription ($35.99/year compared to Todoist's $60/year); Rich mobile Kanban experience with horizontal column swiping, drag-and-drop, and visual completion progress; Community MCP ecosystem provides deep capabilities including Kanban column CRUD and habit tracking; Fast cross-platform sync across mobile, tablet, and desktop.
- Cons: No official first-party MCP server or CLI maintained by TickTick (relies on community Python/Node packages); The official Open API (V1) is limited and lacks endpoints for Kanban column management, forcing MCP servers to use reverse-engineered V2 session endpoints; Hidden API sync quirks (such as raw newlines or backslashes causing API-accepted tasks to fail silent app sync, and recurring tasks requiring start_date); Two-factor authentication (2FA) conflicts with V2 session-based MCP servers; Cloud-only service with no self-hosted or local-first server architecture.
