### Airtable (Kanban view + AI + MCP)
- URL: https://www.airtable.com
- Kind: general-kanban-with-agent-integration
- What: A cloud-based relational database and app-building platform offering multi-view task management (Kanban, Grid, Calendar, Timeline, Interfaces) with built-in AI capabilities. Supports agent-driven record and status manipulation via official and community Model Context Protocol (MCP) servers, REST APIs, and official CLI tools.
- Agent integration: Official remote MCP endpoint (`https://mcp.airtable.com/mcp`) supported by official CLI (`@airtable/mcp-cli` / `github.com/Airtable/airtable-mcp-cli`) and official plugins repository (`github.com/Airtable/skills`) targeting Claude Code, OpenAI Codex, and Cursor, as well as agents consuming `agentskills.io` (OpenCode, Pi, Gemini CLI); popular community local/remote MCP servers include `domdomegg/airtable-mcp-server` (stdio & HTTP transport), `rashidazarang/airtable-mcp`, and `felores/airtable-mcp`; standard REST API (Personal Access Tokens with granular OAuth scopes) supports record creation, filtering (`filterByFormula`), batch status update, and comment tracking.
- Mobile: Native iOS app (Requires iOS 17.0 or later; iPadOS 17.0+; visionOS 1.0+; Formagrid Inc., updated October 2026, Apple App Store); Native Android app (Formagrid Inc., updated October 2026, Google Play Store); responsive web browser support across mobile and tablet devices; Interfaces feature provides mobile-optimized Kanban card views.
- Pricing: Free tier: $0 (unlimited bases, up to 1,000 records per base, 1 GB attachments, up to 5 editors); Team plan: $20/seat/month billed annually ($24/seat/month billed monthly; up to 50,000 records/base, 20 GB attachments); Business plan: $45/seat/month billed annually; Enterprise Scale: custom pricing (pricing as of October 2026).
- Self-host: no (strictly SaaS cloud platform; no self-hosted Docker, on-premises binary, or local file storage options available; enterprise offers enterprise-key management and data governance but hosted on Airtable cloud infrastructure).
- License: proprietary (closed-source core platform; official CLI `@airtable/mcp-cli` and official plugins `Airtable/skills` are open-source under MIT; community MCP servers like `domdomegg/airtable-mcp-server` and `rashidazarang/airtable-mcp` are MIT licensed).
- Activity: Active commercial SaaS (founded 2012 by Formagrid Inc.); official agent ecosystem active in 2026 with recent releases of `Airtable/skills` and `Airtable/mcp-cli` (MIT, active maintenance in 2026); mobile iOS and Android apps actively updated (iOS v11.9 on Oct 7, 2026; Android updated Oct 8, 2026 with Omni AI integration).
- Pros: Highly customizable data schema allowing flexible status columns, tags, and multi-field cards; Official first-class MCP server (`mcp.airtable.com/mcp`) and skills plugins for Claude Code, Codex, and Cursor; Polished native iOS and Android apps with full Kanban interface and real-time synchronization; Powerful automation webhooks and formula filtering allowing agents to query tickets assigned to them; Built-in Omni AI assistant and rich interface designer.
- Cons: Strictly proprietary cloud SaaS with zero self-hosting or offline-local capabilities; API rate limits (5 requests per second per base on standard REST API; usage caps on free tier); Edit seat pricing ($20–$45/user/month) can get expensive if agents require dedicated paid user accounts rather than bot PATs; Kanban cards and schema modifications require network roundtrips unlike local markdown/SQLite kanban boards.
