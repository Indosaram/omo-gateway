### Omnara
- URL: https://www.omnara.com/ (product platform) / https://www.omnara.co/ (mobile/desktop app landing) / https://github.com/omnara-ai/omnara
- Kind: agent-native
- What: Omnara is an open-source managed agent platform and remote command center (YC S25) that runs durable, stateful AI coding agents across cloud sandboxes and local machines. It originated as a mobile, web, desktop, and watch remote control for Claude Code and Codex sessions, and relaunched in September 2026 into a full open-source alternative to Claude Managed Agents and OpenAI's Agents API.
- Agent integration: Official remote MCP server endpoint (`https://app.omnara.com/mcp` registered as `com.omnara/omnara` in the MCP Registry), REST API (OpenAPI v3), TypeScript SDK (`@omnara/sdk`), CLI (`omnara` / `npx omnara`), event webhooks, and daemon (`omnarad`). Integrates directly with Claude Code (`claude mcp add --transport http omnara https://app.omnara.com/mcp`), Codex CLI/desktop (`codex mcp add omnara --url https://app.omnara.com/mcp`), Cursor (`cursor://` deep links / MCP), Slack, Discord, and GitHub PR workflows.
- Mobile: Purpose-built native iOS app, native Android app, and Apple Watch companion app (for notifications, diffs, voice dictation, and approval taps), along with responsive web dashboard (`app.omnara.com`) and macOS desktop app.
- Pricing: Free / Open-source free for self-hosting with zero platform fees. Omnara Cloud has a $0 platform fee when bringing your own model keys and machines. Optional managed compute is pay-as-you-go: models at provider token rates; sandboxes at $0.0414 per GiB RAM/hour online (auto-sleeping when idle) + $0.20016 per GiB RAM/30-day storage retention; custom enterprise pricing for on-prem/VPC deployments and custom SLAs (as of October 2026).
- Self-host: yes — complete control plane self-hostable via Docker Compose (`docker compose -f compose.yaml --profile app up -d`) with Go API, Postgres event log, Redis, RustFS/S3-compatible blob storage, and `omnarad` runner daemon; no enterprise-only restrictions on the core Apache 2.0 repository.
- License: Apache 2.0 (code repository at https://github.com/omnara-ai/omnara).
- Activity: 2,921 GitHub stars; latest release `omnarad-v0.2.6` published on 2026-10-16T00:35:24Z (active commits and daily releases in October 2026).
- Pros: True cross-device remote control including native iOS, Android, Apple Watch, and desktop apps; durable Postgres-backed event log that survives laptop sleep or disconnect by migrating sessions to cloud sandboxes; first-class MCP server and registry support allowing Claude Code, Codex, and Cursor to spawn and control agents; model and sandbox agnostic (supports OpenAI, Anthropic, OpenRouter, Bedrock, Ollama, and 9 sandbox providers including Blaxel, Daytona, Modal, and Unikraft); zero platform fee with complete Apache 2.0 self-hosting.
- Cons: Focuses on hierarchical agent runtimes, execution logs, and chat/thread approval cards rather than a traditional multi-column draggable Trello/Kanban card board; local-to-cloud session state synchronization can experience edge-case latency across dirty worktrees; rapid architectural evolution (pivoting from a pure mobile terminal relay into a full managed-agent control plane in autumn 2026) may require tracking fast-moving config specs; requires running Docker Compose with Postgres, Redis, and shared storage for self-hosted setups.
