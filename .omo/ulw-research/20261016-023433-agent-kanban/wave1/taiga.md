### Taiga
- URL: https://taiga.io/
- Kind: general-kanban-with-agent-integration
- What: Taiga is a free and open-source agile project management platform offering Kanban boards, Scrum sprint backlogs, and integrated issue tracking for cross-functional teams.
- Agent integration: No official vendor MCP server; several active community MCP servers exist (e.g. `taiga-mcp-server` on npm v1.9.20 updated 2026-01-19, `pytaiga-mcp` on GitHub/GHCR supporting stdio & SSE, `mcpTAIGA` by adriapedralbes, `mcp-taiga` on npm); complete REST API (https://docs.taiga.io/api.html) with token/bearer auth covering epics, user stories, tasks, issues, and webhooks; compatible with AI agents (Claude Code, Cursor, Windsurf, Codex) via standard MCP configuration or REST API clients.
- Mobile: No official native iOS or Android app; no official PWA; web UI is partially responsive for tablets/desktop but phone layout is limited (Taiga team confirmed native mobile apps are not in the roadmap, prioritizing responsive desktop/tablet in Taiga Next); community-maintained open-source Android apps exist (e.g., `TaigaMobileNova` by Grigoriym forked from EugeneTheDev's discontinued `TaigaMobile`).
- Pricing: Open-source self-hosted is 100% free; Taiga Cloud (managed SaaS at tree.taiga.io) offers: Free basic trial/public projects, Enthusiast plan at 5€/month (or 50€/year) for 5 public & 5 private projects with 100MB storage and unlimited users, Basic plan at 20€/month (or 200€/year) for unlimited projects with 500MB storage and unlimited users, Premium plan at 60€/month (or 600€/year) for unlimited projects with 3GB storage, priority support, and unlimited users (verified 2026-10-16 at https://taiga.io/deployment-pricing-options/).
- Self-host: yes; officially deployed via Docker and Docker Compose (`taiga-docker` using `.env` setup, launch script, PostgreSQL, RabbitMQ, Celery/async, and Nginx reverse proxy; documentation at https://docs.taiga.io/); no enterprise-only paywall restrictions on self-hosted core features.
- License: MPL 2.0 (Mozilla Public License 2.0) across `taiga-back`, `taiga-front`, and `taiga-docker`.
- Activity: GitHub `taiga-back` 857 stars (commit pushed 2026-10-14); `taiga-docker` 2.2k stars (commit pushed 2026-10-14); `taiga-front` 383 stars (commit pushed 2026-10-14); active stable maintenance.
- Pros: 100% free and open-source under MPL-2.0 with no artificial feature gates on self-hosted instances; Full-featured Kanban with custom swimlanes, WIP limits, epics, and subtasks alongside Scrum sprint boards; Comprehensive REST API and webhooks with active community MCP bridges (`taiga-mcp-server`, `pytaiga-mcp`) ready for Claude Code, Cursor, and Codex; Unlimited users on all cloud tiers without per-seat pricing penalties.
- Cons: No official native mobile apps or polished mobile PWA; Cloud SaaS plans enforce low file storage caps (100MB to 3GB); Self-hosting stack requires multiple moving parts (Docker, PostgreSQL, RabbitMQ, Redis/Celery, Nginx events websocket); No official first-party MCP server maintained by the Taiga core team.
