### Factory.ai Droids (Software Factory & Missions)
- URL: https://factory.ai
- Kind: agent-native
- What: Factory is an agent-native software development platform where autonomous AI agents ("Droids") plan, implement, review, test, and ship production software across CLI, desktop app, web, and team integrations. Its task and workflow orchestration encompasses Factory Missions (multi-agent orchestration with an interactive Mission Control dashboard tracking orchestrator, worker, and validator sub-tasks) and Software Factory (an SDLC lifecycle manager tracking triage, code-generation, validation, release, documentation, and monitoring pipelines with live metrics and repository coverage maps).
- Agent integration: Native agent platform powering proprietary "Droid" agents, while exposing full bidirectional agent orchestration surfaces: Model Context Protocol (MCP client supporting stdio, Streamable HTTP, and legacy SSE transports with persistent tool permissions and org-level host allowlists); Factory Public REST API at api.factory.ai (v0.1.0 endpoints covering Sessions lifecycle, session message trees, child session tracking with includeArtifacts/includeAttention, interrupt, Droid Computers, Environments, Automations, Service Accounts, and AutoWiki); CLI (`droid` interactive REPL and `droid exec` headless runner supporting structured JSON, JSON-RPC via `--input-format stream-jsonrpc --output-format stream-jsonrpc`, and ACP / Agent Client Protocol for IDEs like JetBrains and Zed); official TypeScript SDK (`@factory/droid-sdk`) and Python SDK (`droid-sdk`); Agent Client Protocol (ACP) integration for JetBrains AI Chat and Zed Agent Panel; dedicated extension for VS Code / Cursor / Windsurf; native bi-directional issue delegations from Linear and Jira (assigning issues to `@Factory` moves tickets to In Progress and links PR sessions); and chat delegation from Slack and Microsoft Teams.
- Mobile: Responsive web (no standalone native iOS or Android app listed in documentation or app stores; Factory App is delivered as a cross-platform desktop application for macOS and Windows MSIX, plus cloud-synced web access at app.factory.ai designed with mobile responsive review surfaces and touch-device text sizing settings).
- Pricing: Individual Pro at $20/month (Factory App, Droid CLI, Droid SDK, cloud and local background agents, managed Droid Computers, billing and usage dashboards, 3 rolling rate limit windows); Individual Plus at $100/month (~5x Pro usage); Individual Max at $200/month (~10x Pro usage); Teams at $60/month base + $40/seat/month (up to 10 seats, Pro limits per seat, centralized billing); Business (custom pricing; custom usage limits, SSO/SAML/SCIM, Zero Data Retention, audit logs, admin controls); Enterprise (custom pricing; unlimited seats, dedicated partitioned compute, on-premise/hybrid/airgap options, data residency, SLAs) as of October 2026. Prepaid Extra Usage credits available at $10 minimum.
- Self-host: yes (supports Hybrid and Fully Airgapped enterprise deployment patterns where Droid runs locally on user VMs/containers/bare-metal without outbound internet access, using BYOK custom model endpoints, on-prem OpenTelemetry collectors, and system-managed settings at /Library/Application Support/Factory/settings.json, /etc/factory/settings.json, or C:\Program Files\Factory\settings.json; cloud control plane components such as web app and public API remain proprietary cloud/hosted).
- License: Proprietary (Commercial closed-source platform by Factory AI, Inc. with copyright notices "Copyright © 2025-2026 Factory AI. All rights reserved."; open-source companion components like official plugin marketplace and ESLint plugins distributed under MIT on GitHub).
- Activity: Active commercial product with rapid weekly release cadence (CLI v0.242.0 / Desktop v0.199.0 released October 15, 2026; GitHub repo Factory-AI/factory has 56 stars and official plugins repo Factory-AI/factory-plugins has 114 stars as of October 2026).
- Pros: True agent-native orchestration spanning planning (Missions), worker breakdown, automated validation (QA, code review), and release gates; Deep native integrations with Linear and Jira allow agents to receive assigned issues, report progress, and transition kanban card states automatically; Rich visual Mission Control dashboard in desktop/web apps shows real-time progress, milestones, worker logs, thought process, and validator checkpoints; Flexible deployment models ranging from local terminal CLI to managed cloud computers to fully airgapped enterprise environments with strict security policies; Broad extensibility via MCP (stdio/http/sse), custom droids (.md frontmatter subagents), skills (SKILL.md), plugins marketplace, and JSON-RPC subprocess streaming.
- Cons: Core platform, orchestrator, and cloud dashboard are closed-source proprietary software; No native iOS or Android mobile application (relies on responsive web browsing at app.factory.ai or Slack/Teams notifications on mobile); Not a standalone general-purpose kanban board like Trello or Linear, but rather an agent runtime that delegates to existing issue boards (Linear/Jira) and provides dedicated mission/SDLC stage dashboards; Advanced enterprise governance, SSO, and airgap deployments require custom enterprise contracts; Mission and multi-agent execution consume significant credit/token budgets and require extra prepaid credits when rolling limits are reached.
