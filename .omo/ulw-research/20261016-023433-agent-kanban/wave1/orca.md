### Orca
- URL: https://www.onorca.dev
- Kind: agent-native
- What: Orca is an open-source Agent Development Environment (ADE) designed for orchestrating parallel AI coding agents across isolated git worktrees. It integrates terminal splits, a built-in Chromium browser with Design Mode, git diff annotation, and dedicated agent status tracking boards.
- Agent integration: Orca CLI (`orca`, `orca-cli` skill via npx/git), native MCP/skills registry support (`orca skills install --skill orca-cli`), JSON-RPC / WebSocket internal protocol, and OSC terminal title hooks. Supports 35+ CLI agents including Claude Code, OpenAI Codex, Cursor CLI, OpenCode, Pi / oh-my-pi, Grok, Gemini CLI, Goose, Cline, GitHub Copilot CLI, Aider, and Antigravity. Agents push and read status via the CLI (`orca status --json`, `orca worktree ps --json`, `orca terminal list/read/send`, `orca orchestration check/send/worker-start/task-create/task-update`).
- Mobile: Native iOS companion app available on Apple App Store (ID: 6766130217; requires iOS/iPadOS 15.1+; developed by Lovecast LLC / Stably AI) and native Android app available as direct APK download (`https://www.onorca.dev/download/android`). Not a PWA; thin-client native companion pairing via E2EE local network or Orca Relay WebSockets to monitor status, review terminal scrollback, send prompts, commit git changes, and receive push notifications (APNs/FCM).
- Pricing: 100% Free and open source under the MIT License as of October 2026. No paid tiers, no per-user subscriptions, and no paywalled enterprise features. Users bring their own AI model API keys or CLI subscriptions (BYOK / BYO subscription).
- Self-host: Yes; distributed as local desktop binaries for macOS (Intel & Apple Silicon DMG), Windows (Setup EXE), Linux (AppImage, RPM, DEB, AUR `stably-orca-bin`). Cloud pairing relay and push gateway are fully open-source and self-hostable (`cloud/` workspace in repo; Docker/Cloud Run/Node with PostgreSQL or SQLite).
- License: MIT License (Copyright 2026 Lovecast Inc. / Stably AI).
- Activity: 93,585 GitHub stars on `stablyai/orca` as of October 2026; actively maintained with daily releases (latest stable release v1.4.224 published October 10, 2026; latest repository push October 16, 2026).
- Pros: True git worktree isolation prevents parallel agents from dirtying or conflicting on files; Built-in "Agent Dashboard" kanban board (Settings → Experimental → Agent Dashboard) tracks agents across "Needs You", "Working", "Done", and "Idle" columns with one-click terminal focus; Native mobile companion apps (iOS App Store & Android APK) enable on-the-go monitoring, steering, and push notifications; First-class CLI and orchestration engine (`orca orchestration`) supporting task DAGs, decision gates, and structured supervisor-worker loops; Zero cost, open source MIT license with no agent lock-in (runs any CLI agent).
- Cons: Desktop-bound architecture where the local desktop machine or SSH remote host must stay running for agents to operate; Cloud relay setup requires running separate services if not using the default hosted pairing relay; Multi-agent orchestration protocol and dashboard require compatible CLI flags or hooks for full telemetry detection; Highly rapid release cadence (daily ships) can lead to frequent UI/CLI flag changes across updates.
