### OpenProject
- URL: https://www.openproject.org
- Kind: general-kanban-with-agent-integration
- What: OpenProject is a comprehensive open-source web-based project management system offering Kanban/Agile boards, Gantt charts, Scrum/backlogs, time and cost tracking, and bug tracking. It serves as an open-source, data-sovereign enterprise alternative to Jira, Monday, and Asana.
- Agent integration: Official native Model Context Protocol (MCP) server built into core at endpoint `/mcp` (added in version 17.8 and extended in 17.9 with tools `create_work_package`, `update_work_package`, `create_work_package_comment`, `create_work_package_relation`, `list_statuses`, `list_types`, `list_work_package_comments`, `list_work_package_relations`, `search_work_packages`, `search_projects`, `search_custom_fields`, `search_users`, `search_versions`, `search_portfolios`, `search_programs`, `create_time_entry`, `update_time_entry`, `delete_time_entry`, `search_time_entries`), authenticated via personal API tokens or OAuth with `mcp` scope, compatible with Claude Code, Cursor, Codex, and other MCP-compliant agents; full REST API v3 (HATEOAS/HAL+JSON) with OpenAPI 3.0 specification covering all work package operations, statuses, and custom fields; webhooks for external events; community CLI tools (e.g. `openproject-cli` via API v3). Note: MCP server is an Enterprise add-on (requires Professional, Premium, or Corporate plan).
- Mobile: Native iOS app and native Android app available in Beta (companion apps with mobile dashboards, work package editing, focus timer, camera photo attachment, and OS-level home screen widgets; cited from https://www.openproject.org/docs/mobile-app-guide/) alongside full responsive web design on modern mobile browsers.
- Pricing: Free Community edition (self-hosted, unlimited users, basic agile boards and work packages, no license cost); Enterprise on-premises Basic at €5.95 per user/month (minimum 25 users); Professional at €10.95 per user/month (minimum 25 users, includes native MCP server and SSO); Premium at €15.95 per user/month (minimum 100 users); Corporate on request (minimum 250 users); Enterprise Cloud starts at €5.95/user/month (5 users minimum) with 14-day free trial. Prices observed as of October 2026.
- Self-host: yes; deployment via Docker Compose (recommended for small/medium instances), single Docker container, DEB/RPM packages (packaged installation), or Helm charts on Kubernetes. Community edition is fully self-hostable without restrictions; Enterprise on-premises upgrades require entering an enterprise license token.
- License: GNU General Public License v3 (GPLv3) for core codebase (GitHub: opf/openproject).
- Activity: ~11,000+ GitHub stars; active production development with latest stable releases v17.9.2 (2026-10-15), v17.9.1 (2026-10-01), and v17.9.0 (2026-09-30).
- Pros: Built-in native official MCP server specifically designed for AI agents with work package search/create/update and time tracking; fully self-hostable open-source foundation with strict GDPR and data-sovereignty focus; comprehensive feature set combining Kanban boards, Gantt timelines, Scrum backlogs, and multi-version tracking; active enterprise-backed development with bi-weekly stable updates and mature REST API v3; companion native mobile apps on iOS and Android with OS widgets.
- Cons: Official built-in MCP server feature is gated behind paid Enterprise tiers (Professional plan and above); user minimums for paid self-hosted tiers (minimum 25 users for Basic/Professional, 100 for Premium) create a barrier for solo engineers or tiny teams; heavyweight Ruby on Rails/PostgreSQL backend requiring dedicated server resources compared to lightweight local file kanbans; complex setup and maintenance overhead compared to cloud-native SaaS kanban boards; mobile native apps are still in Beta with some desktop features omitted.
