### Kanboard
- URL: https://kanboard.org
- Kind: general-kanban
- What: Kanboard is a lightweight, minimalistic open-source project management software designed around the Kanban methodology with work-in-progress (WIP) limits. It focuses on simplicity, low resource usage, and clean task visualisation without frontend bloat.
- Agent integration: Community MCP servers exist (e.g., ErnestoCorona/kanboard-mcp in TypeScript/Node with 39 tools supporting Claude Code, Claude Desktop, Cursor, Cline, and Zed; bivex/kanboard-mcp in Go); official integration relies on a comprehensive JSON-RPC 2.0 API over POST (`/jsonrpc.php`) with batch support and dual authentication (global application token `jsonrpc:<token>` or user personal access tokens), official PHP CLI runner (`./cli`), and outgoing HTTP POST webhooks for 18+ events (`task.create`, `task.move.column`, `comment.create`, etc.).
- Mobile: Responsive web interface officially supported; no official native iOS or Android apps provided by the core maintainer due to maintenance overhead (explicitly cited in official FAQ docs: "The development of a native mobile application is left to the community... The web interface is responsive, allowing quick access on mobile devices"); unmaintained/hobby community native wrappers exist on GitHub (e.g. Kandroid, Khanos, SwiftyKanboard).
- Pricing: 100% free and open source; no paid tiers, no commercial licenses, no user-seat limits or hosted SaaS fees as of 2026-10-16.
- Self-host: yes (Docker via official images `kanboard/kanboard:latest` on Docker Hub / GHCR / Quay.io, Docker Compose templates for SQLite, PostgreSQL, and MariaDB, manual PHP/Web server deployment with zero external runtime dependencies on SQLite, or bare PHP 8.1+ archive); no enterprise paywalls or self-host restrictions.
- License: MIT License (permissive open source).
- Activity: 9,907 GitHub stars (as of 2026-10-16); active maintenance mode (commits up to 2026-10-14, latest stable release v1.2.54 published on 2026-08-29; official maintainer Frédéric Guillot accepts bug/security fixes and community PRs while freezing core feature additions).
- Pros: Extremely lightweight and fast with minimal memory/CPU footprint; Built-in JSON-RPC 2.0 API with batch request capabilities ideal for AI agent bulk updates; Zero-config single-file SQLite database support enables instant local spinning up without database servers; Strict WIP limit visual cues and automated action event hooks; Open MIT license without any enterprise paywall or telemetry.
- Cons: Officially in maintenance mode with no new feature development by core author; UI design feels dated and plain compared to modern Web-first boards; No official native mobile application or PWA support out of the box; Real-time updates rely on polling or page refreshes rather than WebSocket subscriptions; JSON-RPC protocol requires customized RPC clients or community MCP wrappers instead of standard REST/GraphQL endpoints.
- Sources: https://kanboard.org, https://github.com/kanboard/kanboard, https://docs.kanboard.org/v1/api/, https://docs.kanboard.org/v1/admin/faq/, https://docs.kanboard.org/v1/dev/webhooks/, https://docs.kanboard.org/v1/admin/docker/, https://github.com/kanboard/kanboard/releases, https://github.com/ErnestoCorona/kanboard-mcp, https://github.com/bivex/kanboard-mcp
- Confidence: high
