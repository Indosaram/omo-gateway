### OpenHands Agent Canvas (All-Hands-AI)
- URL: https://www.openhands.dev (Docs: https://docs.openhands.dev, GitHub: https://github.com/OpenHands/OpenHands, Cloud: https://app.all-hands.dev)
- Kind: agent-native
- What: A developer control center and web-based workspace for autonomous coding agents, managing concurrent conversations, workspaces, file diffs, git operations, and scheduled/event-driven automations. It serves as an agent orchestration and status dashboard connecting local processes, Docker containers, remote VMs, and cloud sandboxes.
- Agent integration: REST API (V1 `/api/v1/app-conversations` with streaming and status polling; Agent Server REST API at `/api/conversations`), WebSocket/SSE live events, Agent Client Protocol (ACP) over stdio for running external CLI agents (Claude Code via `@agentclientprotocol/claude-agent-acp`, Codex via `@zed-industries/codex-acp`, Gemini CLI via `@google/gemini-cli --acp`, Pi via `pi-acp`, and OpenCode via `opencode-ai acp`), CLI (`openhands` / `agent-canvas`), Model Context Protocol (MCP) tool integration, and webhooks for Slack/GitHub/Jira issue-to-PR pipelines.
- Mobile: Responsive web (no native iOS or Android app; no standalone PWA install listed; accessible via mobile browser on phone/tablet when exposed via Tailscale private network or ngrok tunnel as documented in official Phone & Tablet Access guides).
- Pricing: Open Source is free (MIT license, BYOK - Bring Your Own Key); SaaS Individual is free (BYOK or pay-as-you-go at-cost model token pricing with no markup, includes cloud sandbox and Jira/Slack/Git integrations); SaaS/Self-hosted Enterprise offers custom pricing (private VPC deployment, SAML/SSO, unlimited concurrent conversations, Large Codebase SDK, priority support).
- Self-host: yes (Local Node.js 24+ `npm install -g @openhands/agent-canvas`, single or multi-container Docker via `ghcr.io/openhands/agent-canvas:latest`, remote Linux/macOS VM service with optional ngrok/nginx TLS, Kubernetes via official Helm chart, or Modal backend; Enterprise tier supports on-premise VPC deployments).
- License: MIT License (Open Source, Copyright OpenHands contributors).
- Activity: 91,011 GitHub stars, active daily development (latest release v1.27.1 on 2026-10-14, v1.27.0 on 2026-10-12, v1.26.0 on 2026-10-08; status: active beta/v1 production rollout).
- Pros: Broad multi-agent ACP support orchestrating third-party CLIs (Claude Code, Codex, Gemini, Pi, OpenCode) alongside native OpenHands; Flexible hybrid architecture allowing switching between local, Docker, VM, and Cloud backends from a single UI; Built-in Automation Server supporting scheduled cron and webhook-triggered event workflows (GitHub PR review, Issue-to-PR, Slack channel monitoring); Fully open-source under MIT with robust self-hosting options and zero-markup token pricing on cloud.
- Cons: Lacks dedicated native mobile apps (iOS/Android) requiring network tunneling (Tailscale/ngrok) to reach self-hosted instances from mobile devices; Complex multi-repository ecosystem (OpenHands, software-agent-sdk, automation, typescript-client) that requires specific Node 24+ and uv runtime environments; Full Docker sandboxing requires root or privileged mode on the host for nested container execution without Enterprise runtime isolation; Not a traditional column-based drag-and-drop Kanban board (operates primarily as a conversation/task dashboard with status tags, filtering, and execution phase states).
