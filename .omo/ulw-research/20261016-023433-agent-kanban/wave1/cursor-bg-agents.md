### Cursor Cloud Agents (formerly Background Agents) / Cursor Agents Dashboard
- URL: https://cursor.com/agents
- Kind: agent-native
- What: An agent-native cloud execution and monitoring dashboard where parallel coding agents run in isolated cloud virtual machines (or self-hosted worker machines) to inspect code, run terminal commands, execute browser tests, and open pull requests. It provides real-time multi-agent activity monitoring, streaming transcripts, artifact inspection, and cross-device supervision across web, desktop, and mobile.
- Agent integration: Official native integration via Cursor Desktop (Agents Window / Cmd+I), Cursor CLI (`agent` command with `&` background prefix and `agent worker`), Cloud Agents REST API v1 (`POST /v1/agents`, `GET /v1/agents/{id}/runs/{runId}/stream` SSE), TypeScript/Python SDKs, Model Context Protocol (built-in Cursor Cloud MCP diagnostics server + remote HTTP/stdio MCPs), and bidirectional chat/issue triggers via Slack (`@cursor`), GitHub (`@cursor` / `@cursoragent`), and Linear. Supported models include Composer 2.5, Claude 4.5/4.6/4.7/Opus/Sonnet, GPT-5 / GPT-5.1-5.6 / Codex, Gemini 3/4, and Grok 4.5-4.7.
- Mobile: Native iOS and iPadOS app (available on Apple App Store at https://apps.apple.com/app/cursor/id6767085653, requires iOS/iPadOS 26.0+; features live streaming, PR reviews, Design Mode with Apple Pencil / image markup, voice dictation, and Lock Screen / Dynamic Island Live Activities tracking up to 8 parallel agents); Android is supported via Progressive Web App (PWA) through Chrome at https://cursor.com/agents with "Install App" prompt (native Android app planned).
- Pricing: Paid tier required for Cloud Agents. Included in Premium ($30/month), Super ($100/month), Ultra ($200/month), Teams ($30+/user/month), and Enterprise (custom pricing). Free ($0/month) and Plus ($8/month) plans include basic Cursor editor agent requests but exclude Cloud Agents & Automations. Cloud agent runs consume underlying model tokens billed at API list prices with user/team spend limits.
- Self-host: Hybrid / partial self-hosting via "Self-Hosted Machines" (My Machines for individual devboxes/VMs; Team Pools for enterprise teams with autoscaling controllers, Docker, and Kubernetes via Helm anysphere/k8s-workers). Cursor cloud retains orchestration, model inference, and central dashboard, while file editing, shell commands, Docker, and desktop/browser tool calls execute on private workers connecting outbound via HTTPS to api2.cursor.sh (no inbound ports required). Full 100% offline self-hosting of the central coordinator/dashboard is not offered.
- License: Proprietary (Anysphere, Inc.); client tools, Helm charts, and reference worker integrations are published with open-source/open-access components on GitHub (e.g. anysphere/k8s-workers).
- Activity: Active commercial product by Anysphere, Inc. Cursor iOS app v1.13.0 released in October 2026; Agents Window released with Cursor 3 in April 2026; Cloud Agents API v1 in active public beta as of 2026.
- Pros: True agent-native architecture with dedicated VM sandbox per task; multi-surface steering from web, desktop Agents Window, iOS native app with Live Activities, Slack, GitHub, and Linear; built-in artifact pipeline capturing screenshots, screen recordings, terminal logs, and PR diffs; extensible tool ecosystem supporting stdio/HTTP MCP servers, computer use, and automated CI fix loops; enterprise private execution through Self-Hosted Team Pools and Kubernetes workers.
- Cons: Central coordinator, dashboard, and orchestration engine are closed-source SaaS (no fully air-gapped self-hostable server); Cloud Agents are blocked on Free/Plus tiers (requires minimum $30/month Premium plan); model inference generates separate token billing costs on top of the base subscription; no dedicated native Android app yet (relies on PWA); UI is focused on list/thread/conversation views and PR diffs rather than a traditional drag-and-drop column kanban board.
