# Survey: GitHub Copilot Coding Agent, Agent HQ / Agents Panel & GitHub Projects

### GitHub Copilot Coding Agent (Cloud Agent)
- URL: https://github.com/features/copilot/agents
- Kind: agent-native
- What: An autonomous cloud-based coding agent operating inside ephemeral GitHub Actions environments that performs research, codebase planning, multi-file code editing, and automated test execution before opening pull requests or pushing to branches.
- Agent integration: Official GitHub MCP server (`github-mcp-server` toolsets `copilot` and `copilot_issue_intents`), GitHub REST & GraphQL APIs, GitHub CLI (`gh`), issue assignment UI (`Assignees -> Copilot`), Copilot Chat (`/task`), and webhooks (`workflow_run`, `issue_comment`, `pull_request`). Supports delegating tasks to third-party coding agents including Anthropic Claude and OpenAI Codex (Preview), plus custom agents configured via `.github/agents/*.md`.
- Mobile: Native iOS app (GitHub Mobile v1.281.0 on App Store with dedicated "Copilot agent sessions screen", VoiceOver, and filter navigation) and native Android app (GitHub on Google Play); responsive web interface on github.com mobile web.
- Pricing: Included with paid GitHub Copilot plans. Copilot Pro at $10/month (annual plan) or $15/month (monthly plan, 300 premium requests / $10 base credits); Copilot Pro+ at $39/month (annual) or $70/month (monthly, 1500 premium requests / $39 base credits); Copilot Max at $99/month (annual) or $200/month (monthly, $100 base credits); Copilot Business at $19/user/month; Copilot Enterprise at $39/user/month. Tasks consume both GitHub Actions runner minutes and GitHub AI Credits ($0.01 per credit) or legacy premium requests.
- Self-host: No. The cloud agent execution engine runs on GitHub-hosted ephemeral cloud runners; on-premise GitHub Enterprise Server (GHES) does not support hosting the cloud agent runtime itself, though GHES clients can connect outbound to supported features.
- License: Proprietary (SaaS service owned by GitHub / Microsoft).
- Activity: Active commercial product with frequent updates (latest GitHub Mobile v1.281.0 updated October 15-16, 2026; Copilot CLI v1.0.99 pre-released October 2026; AI Credits and third-party agent delegation live 2026).
- Pros: Deepest native GitHub integration with automated PR creation, branch management, and signed verified commits; built-in security scans, secret protection, and automated test validation before PR submission; native issue assignment and real-time prompt-based steering during runs; out-of-the-box MCP server integration for custom repository tools and Playwright web browsing; supports delegating to Claude and Codex in addition to standard Copilot models.
- Cons: Closed proprietary orchestration engine without self-hosted runner support; runs consume metered AI Credits and Actions minutes, causing potential budget exhaustion; steering is not supported for third-party agents; task logs cannot be deleted from cloud storage (archive only).
- Sources: https://github.com/features/copilot/agents, https://github.com/features/copilot/plans, https://docs.github.com/en/copilot/concepts/agents/cloud-agent, https://docs.github.com/en/copilot/how-tos/copilot-on-github/use-copilot-agents/kick-off-a-task, https://docs.github.com/en/copilot/how-tos/copilot-on-github/use-copilot-agents/manage-and-track-agents, https://apps.apple.com/us/app/github/id1477376905
- Confidence: high

### GitHub Copilot Agents Panel / Agent HQ (Mission Control)
- URL: https://github.com/copilot/agents
- Kind: agent-native
- What: The centralized "mission control" agents panel and dashboard on GitHub.com and GitHub Mobile for initiating, observing, steering, filtering, and archiving asynchronous agent sessions across repositories.
- Agent integration: Unified web UI at `github.com/copilot/agents`, repository-level "Agents" tab (`/{owner}/{repo}/agents`), global header icon, Copilot Chat integration (`/task`), and GitHub Mobile agent sessions view. External agents (Claude Code, Cursor, Codex) can trigger agent tasks via the GitHub MCP Server (`assign_copilot_to_issue`, `assign_copilot_to_issue_with_intent`), while REST/GraphQL APIs provide session-linked commit metadata and PR tracking.
- Mobile: Native iOS app (GitHub Mobile v1.281.0 dedicated "Copilot agent sessions screen" with VoiceOver accessibility and repository filtering) and native Android app; full responsive web panel on mobile browser.
- Pricing: Bundled with GitHub Copilot paid tiers (Copilot Pro from $10/mo, Pro+ from $39/mo, Max from $99/mo, Business $19/user/mo, Enterprise $39/user/mo); viewing the panel has no extra cost, while launched agent sessions and real-time steering messages deduct GitHub AI Credits ($0.01/credit) or premium requests.
- License: Proprietary.
- Self-host: No (Hosted exclusively on GitHub.com and GitHub Enterprise Cloud; not available as standalone self-hosted software).
- Activity: Active core platform surface (regularly enhanced throughout 2025-2026; sessions dashboard and mobile filters updated October 2026).
- Pros: Unified cross-repository visibility into all running and historical AI agent jobs; real-time streaming logs with internal reasoning traces, file reads, and diff previews; interactive in-flight steering allowing mid-task course corrections; session-to-commit auditability where verified commit signatures link directly back to session logs; session sharing controls (public/repo-collaborator sharing vs private).
- Cons: Cannot permanently delete cloud agent session traces (archive only); no native kanban column visualization within the panel itself (uses session list and detail drawers); external non-Copilot agents cannot push arbitrary external status cards into this panel without issue/PR proxies; steering messages incur additional AI credit costs.
- Sources: https://github.com/features/copilot/agents, https://docs.github.com/en/copilot/how-tos/copilot-on-github/use-copilot-agents/manage-and-track-agents, https://docs.github.com/en/copilot/how-tos/copilot-on-github/use-copilot-agents/kick-off-a-task, https://docs.github.com/en/copilot/how-tos/copilot-on-github/use-copilot-agents/overview, https://apps.apple.com/us/app/github/id1477376905
- Confidence: high

### GitHub Projects (Projects v2) Boards
- URL: https://github.com/features/issues
- Kind: general-kanban-with-agent-integration
- What: GitHub's modern planning and issue-tracking tool offering adaptable Kanban board, spreadsheet-style table, and roadmap timeline views tightly coupled with GitHub Issues, Pull Requests, and AI agent automation.
- Agent integration: Official GitHub MCP Server (`github-mcp-server` v2.0.2 Go module with `projects` toolset: `projects_list`, `projects_get`, `projects_write` supporting batch updates `update_project_items`, custom fields, and views), GitHub GraphQL API (`ProjectV2`, `ProjectV2Item`, `ProjectV2View`, mutations), GitHub REST API (`/orgs/{org}/projectsV2`, `/users/{username}/projectsV2`), GitHub CLI (`gh project` via CLI extension and built-in commands), and GitHub Actions auto-add/auto-archive workflows. Used by AI agents (Claude Code, Cursor, OpenCode, Codex, Copilot CLI) to read backlog items, create draft tasks, transition Kanban columns (Status fields), and report completion.
- Mobile: Native iOS app (GitHub Mobile supports viewing and editing Project boards, issues, and metadata) and native Android app; responsive web interface accessible via mobile browsers.
- Pricing: Free tier included with all standard GitHub accounts (unlimited public and private projects with core board/table features). GitHub Team ($4/user/month) and GitHub Enterprise ($21/user/month) offer advanced project automations, higher field limits, organization-wide templates, and granular permission management.
- Self-host: Yes, via GitHub Enterprise Server (GHES on-premises appliance running on VMware, Hyper-V, AWS, Azure, GCP); Projects v2 functionality is bundled into standard GHES releases.
- License: Proprietary (GitHub MCP Server connector is open source under MIT License, CLI `cli/cli` is MIT License; GitHub platform is proprietary).
- Activity: Highly active (Projects v2 continuously updated; official `github-mcp-server` v2.0.2 released October 2026 with Go v2 module and protocol 2026-07-28 typed outputs; `gh` CLI 2.62+ with SLSA build provenance).
- Pros: True Kanban board interface with drag-and-drop columns, custom single-select status fields, and iteration/sprint management; first-class MCP toolset (`projects_list`, `projects_write`, batch updates up to 50 items) allowing Claude Code, Cursor, and Codex to autonomously manipulate board columns; native bidirectional sync with GitHub Issues and PRs produced by coding agents; available on-premise via GitHub Enterprise Server; generous free tier for personal and team projects.
- Cons: Generic task board requiring custom status field mappings rather than an out-of-the-box agent runtime visualizer; lacks real-time live telemetry or terminal streaming views for third-party agent processes; GraphQL API query structure for ProjectV2 can be verbose and complex when querying custom field options; rate-limiting applies to high-frequency agent polling on GitHub API.
- Sources: https://github.com/features/issues, https://docs.github.com/en/issues/planning-and-tracking-with-projects/learning-about-projects/about-projects, https://docs.github.com/en/rest/projects/projects, https://github.com/github/github-mcp-server, https://raw.githubusercontent.com/github/github-mcp-server/main/pkg/github/projects.go, https://github.com/github/github-mcp-server/releases, https://apps.apple.com/us/app/github/id1477376905
- Confidence: high
