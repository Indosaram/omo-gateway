### Kan (kan.bn)
- URL: https://kan.bn
- Kind: general-kanban-with-agent-integration
- What: An open-source, minimalist Trello alternative built with Next.js, tRPC, PostgreSQL, and Drizzle ORM designed for organizing tasks, tracking progress, and team collaboration. It features native Model Context Protocol (MCP) support and an OpenAPI REST API allowing AI agents to inspect and manipulate boards and cards.
- Agent integration: Official `@kan/mcp` MCP server package (`npx -y @kan/mcp` or hosted endpoint `https://mcp.kan.bn`) providing 46 tools across 7 resource types (workspaces, boards, lists, cards, checklists, labels, members, comments) compatible with Claude Desktop, Codex CLI, Cursor, and VS Code Copilot; full REST API with Bearer token authentication and OpenAPI 3.0 specification (`https://kan.bn/api/v1` & `/api/v1/openapi.json`); incoming workspace webhooks for event listening (`card.created`, `card.updated`, `card.moved`, `card.deleted`); no standalone official dedicated CLI besides the MCP package runner `kan-mcp`.
- Mobile: PWA and responsive web; no native iOS or Android app found in Apple App Store or Google Play Store (the web application ships a progressive web app manifest at `/manifest.json` enabling 'Add to Home Screen' standalone installation, and includes mobile list snap scrolling merged in PR #510).
- Pricing: Free tier ($0) offering 1 user, unlimited boards, unlimited cards, custom board templates, checklists, and 10MB file uploads (local MCP server works on Free tier); Teams tier at $8 per user/month with unlimited members, unlimited file uploads, custom workspace URL, and priority email support (hosted MCP server requires Teams or higher); Enterprise tier with custom pricing for SAML SSO, advanced admin roles, custom SLA, and dedicated account manager (verified 2026-10-16).
- Self-host: Yes; officially supported via Docker Compose (`ghcr.io/kanbn/kan` and `ghcr.io/kanbn/kan-migrate` with PostgreSQL 15 and optional MinIO/S3-compatible object storage) or one-click deployment template on Railway; full open-source codebase runnable locally with Node.js/pnpm; no artificial enterprise paywalls blocking self-hosted core kanban, REST API, or local MCP server usage.
- License: GNU Affero General Public License v3.0 (AGPL-3.0).
- Activity: GitHub repository `kanbn/kan` has ~5,800 stars and ~510 forks as of 2026-10-16; highly active development with latest releases in the v0.5.x–v0.6.0 series and recent commits in October 2026.
- Pros: First-class official Model Context Protocol (MCP) server exposing 46 fine-grained tools for AI agent automation; Modern, clean, and responsive UI built on Next.js 15, Tailwind, and React 18; Simple self-hosting footprint with official Docker Compose and MinIO support; Fully open-source under AGPLv3 with comprehensive OpenAPI REST API and webhook events; Generous free tier with unlimited boards and cards.
- Cons: No native mobile apps in App Store or Google Play (relies solely on PWA / mobile browser); Hosted cloud MCP endpoint (`mcp.kan.bn`) requires a paid Teams workspace ($8/user/mo), though self-hosted/local MCP via `npx @kan/mcp` is free; Cloud free tier is limited to 1 member per workspace, requiring paid seat upgrades for multi-user collaboration; API rate limiting is enforced at 100 requests per minute on API keys which may throttle rapid agent loops.
- Sources: https://kan.bn, https://kan.bn/pricing, https://github.com/kanbn/kan, https://github.com/kanbn, https://docs.kan.bn, https://docs.kan.bn/introduction, https://docs.kan.bn/integrations/mcp-server, https://docs.kan.bn/guides/self-hosting/introduction, https://docs.kan.bn/guides/self-hosting/s3, https://docs.kan.bn/api-reference/introduction, https://docs.kan.bn/api-reference/webhooks/create-a-webhook, https://github.com/kanbn/kan/releases, https://raw.githubusercontent.com/kanbn/kan/main/AGENTS.md, https://raw.githubusercontent.com/kanbn/kan/main/LICENSE
- Confidence: high (all aspects verified directly from official codebase, package manifests, openapi specifications, MCP source code, and live documentation).
