### Emdash
- URL: https://emdash.sh (also https://emdash.com, GitHub: https://github.com/generalaction/emdash)
- Kind: agent-native
- What: Emdash (YC W26) is an open-source Agentic Development Environment (ADE) desktop app for running multiple AI coding agents in parallel across isolated Git worktrees. It manages tasks, workspaces, git diffs, terminals, in-app browser previews, reusable prompts/skills, and central MCP server sync across local projects and remote SSH machines.
- Agent integration: Detects and orchestrates 37 CLI agent providers (Claude Code, OpenAI Codex, Cursor Agent, OpenCode, Amp, Antigravity, Devin, Droid, GitHub Copilot, Mistral Vibe, Grok, Hermes, Pi, etc.). Provides native ACP (Agent Client Protocol) adapters for 23 providers, automated lifecycle hooks in user-global configs (~/.claude, ~/.codex, etc.) for real-time working/needs-input/done status detection without polling, and centralized MCP management (54+ catalog servers, custom stdio/http servers) synced directly into agent config files (~/.claude.json, ~/.cursor/mcp.json, ~/.codex/config.toml, etc.). Integrates with 12 issue trackers (Linear, Jira, GitHub Issues, GitLab, Asana, Notion, Monday.com, Trello, Plane, Forgejo, Featurebase, Plain) to seed tasks and prompts.
- Mobile: none (desktop only: macOS Apple Silicon/Intel, Windows installer/portable, Linux x64/ARM64 AppImage/DEB/RPM; no native iOS/Android apps, no PWA, no web dashboard - cite: https://emdash.sh and repo README).
- Pricing: Free and 100% open-source under Apache-2.0. All desktop features are free with no seat fees, local or remote SSH work has no paywall, and users bring their own LLM API keys / CLI subscriptions (as of 2026-10-16). Commercial Emdash Cloud for teams is mentioned for enterprise managed environments at emdash.com/cloud.
- License: Apache-2.0 (permissive OSI open source license).
- Activity: Active OSS project (YC W26 batch). GitHub releases show v1.2.8 released in mid-October 2026 with recent canary pre-releases (canary.101) and commits on 2026-10-14. GitHub stars count is masked by API rate-limit/dynamic badges (badge displays total downloads over 1M on site).
- Pros: 100% free and permissive Apache-2.0 open-source license; Comprehensive cross-platform desktop support (macOS, Windows, Linux x64/ARM64); Broadest CLI agent ecosystem support (37 agent providers detected, 23 ACP-capable); First-class MCP server management syncing stdio/http servers across all agent config formats; Full local-first privacy with SQLite persistence and optional self-hosted remote machines via SSH/SFTP.
- Cons: No mobile app, responsive web UI, or PWA (desktop computer required); No hosted remote cloud workspace service provided out-of-the-box (relies on user-owned SSH servers or custom remote boxes); Lacks a dedicated inbound MCP server for external agents to programmatically query/drive Emdash itself (MCP is outbound to agent configurations); Task kanban board is focused on worktree/task units rather than a traditional multi-column Kanban board.

### Superset
- URL: https://superset.sh (Docs: https://docs.superset.sh, GitHub: https://github.com/superset-sh/superset)
- Kind: agent-native
- What: Superset is an agentic IDE and parallel agent orchestrator designed to scale execution to 100+ coding agents simultaneously. Each task runs in an isolated Git worktree with dedicated branches, terminals, live diff viewer, dev-server port detection with in-app browser (with element Design Mode), recurring automations, and an integrated Tasks view with both table and Kanban board modes.
- Agent integration: Deep multi-layered agent integration: (1) First-class built-in MCP server (`https://api.superset.sh/mcp`) exposing tools for tasks (`tasks_list`, `tasks_create`, `tasks_update`, `tasks_delete`, `tasks_statuses_list`), workspaces (`workspaces_list`, `workspaces_create`, `workspaces_update`, `workspaces_delete`), agents, terminals, pages, automations, and hosts; (2) Full-featured static `superset` CLI with JSON/quiet output modes for scripting, CI/CD, and agent self-orchestration; (3) Programmatic `@superset_sh/sdk` TypeScript SDK; (4) Agent lifecycle hooks and command wrappers (~/.superset/bin) for 22+ CLI agents (Claude Code, OpenAI Codex, OpenCode, Cursor Agent, Amp, Antigravity, Mistral Vibe, Grok, Hermes, Pi, Devin, etc.) supporting working/blocked/idle status, auto-resume, fork-session, subagent menus, and quota meters.
- Mobile: Native iOS and iPadOS app available on Apple App Store ("Superset", App Store ID: id6788926383, requires iOS 26.0 / iPadOS 26.0+, requires Superset Pro; updated v1.1.3 on Oct 8, 2026). Supports reviewing live terminal outputs, dictating instructions, answering approval prompts, reviewing file diffs, and merging PRs. Android is currently waitlist-only (no Android native app yet); no supported general web dashboard or PWA (cite: https://superset.sh/mobile, https://apps.apple.com/us/app/id6788926383, https://docs.superset.sh/faq).
- Pricing: Freemium model (as of October 2026). Free tier: $0 (1 user, local workspaces, desktop app, CLI, unlimited local workspaces and projects). Pro tier: $20/user/month billed monthly, or $15/user/month ($180/year) billed annually (unlimited users, remote access via relay, scheduled automations, Linear integration, Slack integration, Superset Mobile app access). Enterprise tier: Custom pricing, annual billing (adds SAML SSO/SCIM, IP restrictions, audit logs, SOC 2 Type II report, uptime SLA, dedicated support). Users bring their own AI model API keys / CLI subscriptions.
- Self-host: Yes. Desktop app and CLI are local-first, storing state in local SQLite (`~/.superset/host/<orgId>/host.db`). The full monorepo source code is available on GitHub to inspect, modify, build, and self-host for internal teams (`./.superset/setup.local.sh` runs local Postgres, neon-proxy, Redis Docker stack). Remote hosts can be added over SSH (`superset hosts add`). Limitation: repackaging Superset as a competing commercial managed service is prohibited under ELv2.
- License: Elastic License 2.0 (ELv2) - source-available, free to use, modify, and self-host internally, but not OSI-approved open source. Desktop app binaries are free forever for local parallel agent execution.
- Activity: Extremely active. Release `desktop-v1.38.0` and `cli-v1.38.0` along with daily canary releases on 2026-10-16. Monorepo shows frequent daily commits by core maintainers (Avi Peltz, Kiet, Satya Patel). GitHub stars unverified due to API rate limit.
- Pros: Complete end-to-end orchestration surface (Desktop IDE + powerful CLI + TypeScript SDK + official inbound MCP server); Native iPhone and iPad mobile app with live terminal stream, voice dictation, and diff review; Built-in Tasks view with both List and Kanban board views synced with Linear and GitHub issues; Rich collaboration features including Superset Pages (shareable HTML previews with comment threads) and browser element Design Mode; Scalable remote host management (`superset hosts add`) and scheduled background automations.
- Cons: Mobile app requires paid Pro tier ($15-$20/user/mo) and is restricted to iOS/iPadOS (Android is still waitlist-only); Desktop app officially supports macOS only (Linux x64 AppImage is experimental; Windows is not yet available); Elastic License 2.0 (ELv2) is source-available rather than OSI-permissive open source; Cloud relay and team collaboration features require Superset account/cloud coordination (not purely offline peer-to-peer).
