### GitLab Issue Boards (CE Self-Host & SaaS)
- URL: https://about.gitlab.com/
- Kind: general-kanban-with-agent-integration
- What: GitLab Issue Boards provide visual Kanban and Scrum task management integrated directly with repositories, CI/CD pipelines, and work items. Teams and AI agents can track progress across lists defined by labels, assignees, milestones, iterations, or status.
- Agent integration: Official REST API (`/api/v4/projects/:id/boards`, `/api/v4/issues`), GraphQL API (`boards`, `issueSetLabels`), official CLI (`glab issue list`, `glab issue update`, `glab issue create`), webhooks (issue events, label changes), community & official Model Context Protocol (MCP) servers (e.g. `@modelcontextprotocol/server-gitlab` supporting issue creation/listing and project management; compatible with Claude Code, Cursor, Codex, and any MCP-compliant agent).
- Mobile: Responsive web interface (GitLab web UI is mobile-optimized; official native mobile apps were historically deprecated/discontinued; third-party open-source mobile clients like GitFox and LabCoat exist on iOS/Android).
- Pricing: Free tier ($0/month for CE self-hosted unlimited users, or SaaS GitLab.com with 5 users/group limit and basic boards); Premium ($29 per user/month billed annually for scoped boards, multiple group boards, iteration/milestone/assignee lists, WIP limits); Ultimate ($99+ / custom per user/month with epic swimlanes, health status, and full portfolio governance); as of October 2026.
- Self-host: Yes; Omnibus packages (Debian/RPM), Docker container images (`gitlab/gitlab-ce`), Kubernetes Helm charts, and source builds; Community Edition (CE) is fully free self-hosted with no license key required; Enterprise Edition (EE) features require paid subscription licenses.
- License: Open-core; Community Edition (CE) is MIT Expat license; Enterprise Edition (`/ee`) contains proprietary components under GitLab Enterprise License.
- Activity: GitLab Community/Enterprise repository on gitlab.com has over 6,100+ stars, 12,400+ forks, and active continuous commits/releases (latest activity October 2026; release 18.x active).
- Pros: Tight native binding to source code, merge requests, commits, and CI/CD pipelines; rich automation via Webhooks, REST API, GraphQL, and glab CLI; full data sovereignty and self-hosting control under MIT CE license; broad AI agent support via standard REST APIs and official/community MCP servers; built-in quick actions (e.g. `/label`, `/close`, `/assign`) parseable from commit messages or agent comments.
- Cons: Advanced Kanban features (assignee lists, WIP limits, epic swimlanes, milestone lists, multiple group boards) gated behind paid Premium/Ultimate tiers; self-hosted GitLab CE requires significant compute memory (minimum 4GB-8GB RAM recommended); no official first-party native mobile app for standalone Kanban management; setup and administrative overhead for self-hosting is heavy compared to lightweight dedicated kanban tools.
