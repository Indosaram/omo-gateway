### AppFlowy (Board View)
- URL: https://appflowy.com (Docs: https://docs.appflowy.io, GitHub: https://github.com/AppFlowy-IO/AppFlowy)
- Kind: general-kanban
- What: AppFlowy is an open-source, privacy-first Notion and Trello alternative built with Flutter and Rust that includes flexible database Board (Kanban) views for visualizing, grouping, and tracking tasks. The board view visualizes underlying database rows categorized by single-select, multi-select, URL, checkbox, or date-time properties with full drag-and-drop card interaction.
- Agent integration: REST OpenAPI specification bundled at `/api/docs/openapi.json` (Swagger UI at `/api/docs`) supporting programmatic CRUD on workspaces, pages, database views, and database rows (`GET/POST /api/workspace/{workspace_id}/database/{database_id}/row`, row deletions, etc.); self-hosted MCP service integration exists in the commercial backend with database tools for creating timeline/form views and formula fields (`mcp.tool.call` audited in release v0.19.0+); no official public standalone community MCP server published for direct zero-config Cursor/Claude Code/Codex plugins yet, but custom agents can interact via standard HTTP REST API using GoTrue bearer JWT tokens or custom CLI scripts.
- Mobile: Native iOS app (available on Apple App Store for iPhone, id6457261352), native Android app (available on Google Play Store, Android 10+, ARM64/x86_64; ARMv7 unsupported, APK also downloadable directly via GitHub releases), web app (`AppFlowy-Web`), and desktop apps (macOS DMG/ZIP universal/arm64, Windows EXE/ZIP, Linux deb/rpm/AppImage/tar.gz/FlatHub/Snapcraft). (Sources: App Store listing, GitHub README, Google Play Store).
- Pricing: Cloud Personal: Free ($0/month, 1 workspace owner, unlimited guest editors, 100 MB storage, 7 MB file uploads, 7-day version history); Cloud Pro: $12/member/month (billed annually, saves 25%, or monthly billing, unlimited members, unlimited storage, unlimited file uploads, 90-day version history, full AI features); Self-Hosted Free Tier: $0 (1 user seat per instance, up to 3 guest editors, web app access, publish pages, unlimited workspaces); Self-Hosted Paid/Commercial Tiers: paid per-seat plans (Seed/Enterprise) for multi-user enterprise auth (SCIM 2.0, LDAP, SAML), audit logging, and team seats. Pricing observed as of October 2026.
- Self-host: Yes. Fully self-hostable via Docker Compose using the official `AppFlowy-SelfHost-Commercial` deployment repository (orchestrating `appflowy_cloud` Rust backend, `gotrue` auth, PostgreSQL with `pgvector`, Redis, MinIO S3-compatible storage, `appflowy_search` on port 4002, `appflowy_web`, and optional `appflowy_backup` and `appflowy_ai` containers), or local desktop offline-first storage where files remain 100% on local disk without any server required. Multi-user enterprise features (SCIM, LDAP, full multi-seat admin) require commercial self-host license tiers, while the free self-hosted tier includes 1 user seat and 3 guest editors.
- License: GNU Affero General Public License v3.0 (AGPL-3.0) for core client applications (AppFlowy Flutter / Web), while modern AppFlowy Cloud backend follows an open-core commercial model governed by the AppFlowy Self-Hosted Commercial License Agreement (proprietary/commercial for backend cloud distribution; legacy backend repo is archived AGPLv3).
- Activity: 77,411 GitHub stars, 6,070 forks; active development with latest desktop release v0.14.8 published on 2026-10-08 / 2026-10-13, and latest server release v0.19.6 published in October 2026.
- Pros: True local-first data privacy with offline operation support; native Flutter performance across all desktop and mobile platforms (iOS, Android, macOS, Windows, Linux); robust database board view with customizable grouping, properties, formulas, and rollups; built-in REST API with bundled OpenAPI/Swagger interactive UI for scripting and database-row manipulation; active open-source community and rapid release cadence.
- Cons: Cloud backend has transitioned to an open-core commercial model where multi-user self-hosting beyond 1 seat requires commercial licensing; no out-of-the-box prepackaged Claude Code/Cursor MCP plugin (developers must script against REST endpoints or use internal MCP adapters); board view is part of an all-in-one Notion-like workspace rather than a lightweight dedicated agile board; setting up self-hosted cloud requires running 7+ containers (Postgres, Redis, MinIO, GoTrue, Cloud, Search, Web).
