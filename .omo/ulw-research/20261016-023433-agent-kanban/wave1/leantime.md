### Leantime
- URL: https://leantime.io
- Kind: general-kanban-with-agent-integration
- What: Open-source, goal-focused project management and kanban system designed for non-project managers, with behavioral science features tailored for neurodivergent teams (ADHD, autism, dyslexia). Combines kanban boards, milestones, Gantt timelines, strategy docs, and native AI capabilities.
- Agent integration: Official MCP (Model Context Protocol) server running over Streamable HTTP at `/mcp` (or stdio CLI bridge via `php bin/leantime lt-mcp:start`), personal access tokens (`Authorization: Bearer <token>`) or API keys (`x-api-key`), JSON-RPC 2.0 API (`/api/jsonrpc`), CLI (`php bin/leantime`), and outgoing notifications/webhooks; explicitly tested and documented for Claude Code, Cursor, VS Code, Claude Desktop, and ChatGPT.
- Mobile: Responsive web; native iOS and Android apps are currently in private TestFlight / internal development with push notification backend integration in progress (GitHub Issue #3398 / bundle ID `io.leantime.mobile`, no public App Store/Google Play release yet; no PWA manifest).
- Pricing: Open-source self-hosted core is 100% free; Cloud Leantime Pro is $10/user/month (billed monthly) or $8/user/month (billed annually, 2 months free) with a 14-day free trial; self-hosted MCP Server plugin is sold via Marketplace starting at $29 (1–3 users), $59 (4–10 users), $129 (11–25 users), up to $859 (101–250 users) perpetual/license tiers; custom Enterprise support upon request (as of October 2026).
- Self-host: yes — Docker Compose (`leantime/leantime:latest`), manual PHP/MySQL archive (`Leantime-vx.x.x.zip`), and community Proxmox VE scripts; core features (Kanban, Milestones, Sprints, Wikis, Timetracking, JSON-RPC API) are fully functional self-hosted with no user-count restrictions on OSS core; select plugins (Strategy Pro, Whiteboard, MCP Server) are licensed via Marketplace.
- License: AGPL-3.0 (GNU Affero General Public License v3.0) with an explicit exception allowing proprietary/commercial plugins under `/app/Plugins`.
- Activity: Active OSS project; ~11,837 GitHub stars; latest release v3.12.0 published on 2026-10-15; actively maintained on GitHub.
- Pros: First-class native MCP server support with direct Streamable HTTP and stdio endpoints for Claude Code, Cursor, and Windsurf; Clean, neurodivergent-friendly Kanban and milestone hierarchy connecting daily tickets to strategic goals; Fully self-hostable with standard Docker and lightweight PHP/MySQL footprint without heavy JVM/enterprise bloat; Rich programmatic surface via JSON-RPC 2.0 API and granular personal access tokens.
- Cons: Self-hosted MCP server requires purchasing a separate marketplace plugin tier ($29+); Public mobile apps are not yet launched on the iOS App Store or Google Play (TestFlight / in-progress push notification build); Webhook triggers out-of-the-box are limited compared to webhook-first tools like Linear or GitHub, requiring JSON-RPC polling or messenger integration plugins; PHP/MySQL stack may feel less modern for teams expecting pure TypeScript/Go microservices.
