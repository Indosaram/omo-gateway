### Terragon (Terragon Labs)
- URL: https://www.terragonlabs.com/
- Kind: agent-native
- What: A cloud orchestrator and background task board for delegating asynchronous coding tasks to remote AI coding agents in isolated sandboxes. Automatically provisions container environments, checks out code, runs agents like Claude Code and OpenAI Codex, and reports real-time task status leading to GitHub pull requests.
- Agent integration: Official CLI (`terry`) on npm (`@terragon-labs/cli`); built-in Model Context Protocol server via `terry mcp` exposing `terry_list`, `terry_create`, and `terry_pull` for tools like Claude Code and Cursor; supports outbound MCP configuration (command-based, HTTP, SSE) inside agent sandboxes; supports multiple coding agents including Anthropic Claude Code (Opus 4.5/Sonnet 4.5/Haiku 4.5), OpenAI Codex (GPT-5/GPT-5.1/GPT-5.2 Codex series), Sourcegraph Amp, Google Gemini CLI, and OpenCode; Slack bot app mentions; GitHub App mentions; REST API was planned/in-progress as 'Coming soon' for Pro before shutdown.
- Mobile: Responsive web and Progressive Web App (PWA); officially documented install instructions for iOS Safari ('Add to Home Screen') and Android Chrome ('Add to Home screen'); no dedicated native iOS or Android app stores listings.
- Pricing: As of service operation (prior to Feb 9, 2026 shutdown): 14-day free trial with $10 AI credits; Core plan at $25/user/month (2 CPU / 4 GB RAM sandbox, up to 3 concurrent tasks, 5 automations); Pro plan at $50/user/month (higher specs, up to 10 concurrent tasks, unlimited automations, upcoming REST API); Pay-as-you-go AI credits available in $20 increments at cost, or BYO (Bring Your Own) subscriptions/API keys (Claude Pro/Team, ChatGPT Plus/Team/Enterprise, OpenRouter/API keys).
- Self-host: Yes (partial/community open-source); codebase released as open-source snapshot on GitHub (`terragon-labs/terragon-oss`) on Jan 16, 2026 under Apache-2.0; requires Node.js v20+, pnpm 10+, PostgreSQL, Redis, local tunneling (ngrok/Cloudflare), sandbox provider (e2b / Docker), Cloudflare R2, Stripe CLI, and GitHub App credentials; provided as-is without commercial hosting maintenance.
- License: Apache-2.0
- Activity: 261 GitHub stars, 43 forks (as of October 2026); last commit February 10, 2026 (`docs: remove desktop and VS Code extension mentions`); official SaaS service shut down on February 9, 2026 citing unsustainable unit economics/market traction against official vendor cloud web agents (Claude Code Web, Codex Web).
- Pros: Seamless git workflow with automatic sandbox isolation, branch creation, AI commit generation, and PR lifecycle tracking; Rich native agent support (Claude Code, OpenAI Codex, Amp, OpenCode, Gemini CLI) with BYO subscription credentials; Built-in `terry` CLI and MCP server bridge enabling bidirectional control and seamless local handoff (`terry pull --resume`); Real-time streaming status dashboard with CI and PR visual badges, filterable list/board views, and browser notifications; Flexible automation triggers via cron schedules, GitHub App mentions, and Slack bot integrations.
- Cons: Official managed SaaS platform shut down on February 9, 2026 and new user signups are permanently disabled; Open-source self-hosting requires complex multi-service infrastructure setup (Postgres, Redis, R2, sandbox provider like E2B, GitHub App, webhooks); No native mobile app store clients (relies exclusively on PWA / mobile browser); REST API for external third-party automation was never fully finalized/released before shutdown; Task board view is primarily structured as a reactive status list/table with status filters rather than a customizable multi-column drag-and-drop Kanban board.
